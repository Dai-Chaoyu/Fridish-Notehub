# Fridish-Notehub 芝士炒鱼的资料库

更适合中山大学软件工程学院宝宝的期末复习资料，（基本）全部由制作者手搓而成，欢迎来看看！

> 因为是手搓，所以难免有错漏，欢迎提 issue or PR or 进群讨论～
>
> ![入群二维码](./入群二维码.jpg)

## 为什么选择芝士炒鱼的资料库？

- **基本纯手搓**：不是把课本目录抄一遍，是按自己的理解重写的，以确保我自己能看懂为第一要务

- **严格按课件做**：章节和课件/课本一一对应，课上讲了什么就记什么

    包括高数的手写笔记是根据中大实际使用北大版高数进行制作，并非和大多数网络资料一样使用同济版高数

    > 制作者来自 2024 级，内容的更新基本也是在本学期期末更新完毕。课件要是更新了，欢迎提 issue 或 PR 补上

- **一门都不落**：六门专业课之外，高数、线代、概统的手写笔记也在这个仓库里（放网盘了），目前来看资料相当的完整啊

- **资深强迫症患者出品**：内容逻辑是通的，格式是统一的，排版也是认真调过的，尽量把阅读体验做舒服

- **还在更新**：数据库系统原理和编译原理在补（现在就在学这俩），相信我可以更新完的……吧？
