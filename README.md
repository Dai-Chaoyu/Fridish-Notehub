## 汇总与 HTML

已完成整理的六门课程，目录内还有：

- `<课程名>.md`：由各章节文档拼接生成的完整汇总文档。
- `<课程名>.html`：用 Typora 从汇总文档导出的单文件 HTML（主播比较喜欢的 Claude 风格的主题），图片已以 base64 内嵌，可直接用浏览器打开和打印。

## 阅读说明

- 建议用支持 Markdown 的编辑器打开，Typora、Obsidian、VS Code 都可以；HTML 直接用浏览器打开即可。
- 笔记里有少量 LaTeX 公式和 mermaid 流程图，需要渲染器支持；纯文本预览会看到源码。
- 数据库系统原理、编译原理两门仍在编写中，内容会继续补充。
