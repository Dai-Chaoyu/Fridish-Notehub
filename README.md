## 汇总与 HTML

已完成整理的六门课程，目录内还有：

- `<课程名>.md`：由各章节文档拼接生成的完整汇总文档。
- `<课程名>.html`：用 Typora 从汇总文档导出的单文件 HTML，图片已以 base64 内嵌，可直接用浏览器打开或单独分发。

图片资源位置：

- 计算机组成原理、数据结构：`<课程名>.assets/`。
- 操作系统：`two-stages-page-table.svg`、`c_matrix_speedup.png` 直接放在课程目录内。
- 数据库系统原理：第 7 讲的 `.png` 与 `.drawio` 直接放在课程目录内。

所有 Markdown 中的图片引用均已改为相对路径。

## 阅读说明

- 建议用支持 Markdown 的编辑器打开，Typora、Obsidian、VS Code 都可以；HTML 直接用浏览器打开即可。
- 笔记里有少量 LaTeX 公式和 mermaid 流程图，需要渲染器支持；纯文本预览会看到源码。
- 章节编号按课程进度整理，存在有意的跳跃：程序设计 II 没有第 8 章，数据结构没有第 8 章，程序设计 I 有两个第 13 章。
- 数据库系统原理、编译原理两门仍在编写中，内容会继续补充。
