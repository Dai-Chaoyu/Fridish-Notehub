## 阅读说明

- 建议用支持 Markdown 的编辑器打开，Typora、Obsidian、VS Code 都可以。
- 计算机组成原理、数据结构两篇里有少量用 LaTeX 写的公式和 mermaid 流程图，需要渲染器支持；纯文本预览会看到源码。
- 这两篇里还有 22 张截图，路径写的是本机 Typora 图片目录的绝对路径（`/Users/daichaoyu/Library/...`），换台机器或在线预览会加载不出来。
- 四个软链接指向仓库外的本地目录（`../Documents/课件/...`），克隆到别的机器后是断的，这部分内容得自己配好路径。
- 覆盖范围按课程进度整理，编号有跳跃：程序设计 II 没有 08，数据结构没有编号第八章，计组没有编号第五章。
