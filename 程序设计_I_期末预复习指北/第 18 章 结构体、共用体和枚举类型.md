# 第 18 章 结构体、共用体和枚举类型
1. #### 结构体的概念与定义

    - 基本数据类型与聚合数据类型

        - 基本数据类型包括整数（`long long `, `(long) int`, `short`, `char`, `_Bool`）和浮点数（`float`, `double`, `long double`）
        - 聚合数据类型包括数组（相同类型数据的连续摆放）和结构体、共用体（多种类型数据的聚合）

    - 结构体的定义

        结构体（Structure）是由用户自定义的聚合数据类型（Aggregate Type），由若干个具有相同 / 不同数据类型的成员（Member）组成，每个成员有独立的名称和数据类型

        结构体本身是 “类型声明”（而非变量），需基于该类型定义变量后才能存储具体数据

    - 结构体的定义方法

        结构体定义遵循固定语法框架，核心格式如下：

        ```c
        // 基础语法格式
        struct 结构体标签（Tag） {
            数据类型1 成员名1; // 成员定义：类型+名称+分号
            数据类型2 成员名2;
            // ... 更多成员
        }; // 末尾分号是语法要求，不可省略
        ```

        - 其他常见定义形式

        | 定义形式             | 语法示例                               | 特点                     |
        | -------------------- | -------------------------------------- | ------------------------ |
        | 定义时直接创建变量   | `struct Student {int id;} stu1, stu2;` | 一次完成类型 + 变量定义  |
        | 匿名结构体（无标签） | `struct {int id; char name[20];} stu;` | 无法复用类型，仅临时使用 |

    - 定义结构体的易错易漏注意事项

        1. 最高频错误：遗漏末尾的分号 `;`

        结构体定义以`}`结束后，**必须加分号**（结构体定义是完整的声明语句），这是最易犯的错误

        ❌ 错误：

        ```c
        struct Student {
            int id;
            char name[20];
        } // 漏分号，编译报错：syntax error : missing ';' after struct
        ```

        ✅ 正确：

        ```c
        struct Student {
            int id;
            char name[20];
        }; // 末尾分号不可少
        ```

        2. 成员定义格式错误

        结构体内部的每个成员，语法需和普通变量一致：`数据类型 成员名;`，需注意两点：

        - 每个成员行末尾必须加`;`

        - 不能颠倒 “数据类型” 和 “成员名” 的顺序

        
        ❌ 错误：
        
        ```c
        struct Student {
            int id // 成员行漏分号
            name[20] char; // 类型和名称顺序颠倒
        };
        ```
        
        ✅ 正确：
        
        ```c
        struct Student {
            int id; // 类型在前、名称在后，末尾加分号
            char name[20];
        };
        ```
        
        3. C 语言中遗漏`struct`关键字
        
        C 语言中，定义结构体变量时必须写`struct 标签`（除非用`typedef`重命名）；C++ 可省略，但为了兼容性建议保留
        
        ❌ 错误（C 语言）：
        
        ```c
        struct Student {int id;};
        Student stu1; // 报错：未定义标识符"Student"
        ```
        
        ✅ 正确（C 语言）：
        
        ```c
        struct Student {int id;};
        struct Student stu1; // 保留struct关键字
        ```
        
        4. 结构体标签重复定义
        
        同一个作用域内，结构体标签不能重复，否则会报 “重定义” 错误
        
        ❌ 错误：
        
        ```c
        // 第一次定义Student
        struct Student {int id;};
        // 同一作用域重复定义，编译报错
        struct Student {char name[20];};
        ```
        
        ✅ 正确：
        
        - 不同作用域（如不同函数内）可定义同名标签
        - 同一作用域使用不同标签，或通过 “结构体嵌套” 扩展成员
        
        5. 结构体嵌套的 “提前引用” 问题
        
        若结构体 A 嵌套结构体 B，需确保 B 的定义在 A 之前（或用指针规避）
        
        ❌ 错误（提前引用）
        
        ```c
        struct A {
            int a;
            struct B b; // B未定义，无法直接作为成员
        };
        struct B {int b;};
        ```
        
        ✅ 正确做法 1（调整顺序）：
        
        ```c
        // 先定义B，再定义A
        struct B {int b;};
        struct A {
            int a;
            struct B b; // B已定义，可直接嵌套
        };
        ```
        
        ✅ 正确做法 2（用指针）：
        
        ```c
        struct B; // 声明B（告诉编译器B是结构体类型，暂未定义）
        struct A {
            int a;
            struct B *b; // 指针仅需知道B是结构体，无需完整定义
        };
        struct B {int b;};
        ```
        
        6. 初始化时的值匹配问题
        
        结构体变量初始化需用`{}`包裹值，且顺序需与成员定义顺序一致（C99 及以上支持指定成员初始化）
        
        ❌ 错误（值数量不匹配）：
        
        ```c
        struct Student {int id; char name[20]; float score;};
        
        // 少了score，虽C语言会默认置0，但易出错
        struct Student stu = {101, "Zhang San"};
        ```
        
        ✅ 正确（C99 指定成员初始化，更清晰）：
        
        ```c
        struct Student stu = {
            .id = 101,
            .name = "Zhang San",
            .score = 95.5
        };
        ```

2. #### `typedef` 关键字

    关键字 `typedef` 可以为类型起一个别名

    ```
    typedef oldName newTypeName;
    ```

    例如：

    ```c
    // 赋予匿名结构体别名，方便后续调用
    typedef struct {
    	...
    }MyStruct;
    
    // 给数组命名，提高程序可读性
    typedef int MATRIX_3[3][3];
    
    // 给函数指针再命名，便于阅读
    typedef int (*CMP_F)(int, int);
    ```

3. #### 结构体运算与用法

    1. ##### 结构体的赋值

        我们定义一个基础的结构体作为示例，后续所有赋值方法都基于这个结构体

        ```c
        // 定义一个学生结构体
        typedef struct {
            int id;         // 学号
            char name[20];  // 姓名
            float score;    // 成绩
        } Student;
        ```

        ###### 方法 1：逐个成员赋值（最基础，兼容所有 C 版本）

        这是最通用的赋值方式，直接通过`.`操作符访问结构体的每个成员并赋值，适合 C89 及所有更高版本的标准

        ```c
        int main() {
            Student stu1;  // 定义结构体变量
            
            // 逐个给成员赋值
            stu1.id = 1001;
            // 字符串不能直接用=赋值，需用strcpy
            strcpy(stu1.name, "张三");
            stu1.score = 92.5;
            
            // 打印验证
            printf("学号：%d，姓名：%s，成绩：%.1f\n", stu1.id, stu1.name, stu1.score);
            return 0;
        }
        ```

        **关键点**：字符串成员不能直接用`=`赋值，需借助`strcpy`（需包含`<string.h>`）；数值型成员可直接赋值

        ###### 方法 2：初始化时整体赋值（聚合初始化）

        在定义结构体变量的同时完成赋值，分为两种形式：

        2.1 按成员顺序初始化（C89 及以上）

        按结构体成员定义的顺序依次赋值，必须一一对应，不能跳过

        ```c
        int main() {
            // 定义时按id、name、score的顺序赋值
            Student stu2 = {1002, "李四", 88.0};
            
            printf("学号：%d，姓名：%s，成绩：%.1f\n", stu2.id, stu2.name, stu2.score);
            return 0;
        }
        ```

        2.2 指定成员初始化（C99 及以上）

        无需按顺序，通过`成员名:`指定要赋值的成员，未指定的成员会被初始化为 0（数值型）或空字符串（字符数组）

        ```c
        int main() {
            // 不按顺序，指定成员赋值
            Student stu3 = {
                .name = "王五",
                .id = 1003,
                .score = 95.5
            };
            
            printf("学号：%d，姓名：%s，成绩：%.1f\n", stu3.id, stu3.name, stu3.score);
            return 0;
        }
        ```

        ###### 方法 3：结构体变量之间直接赋值（浅拷贝）

        C 语言支持将一个已赋值的结构体变量直接赋值给另一个同类型的结构体变量，本质是**逐字节拷贝**（浅拷贝），适合简单结构体（无指针成员）

        ```c
        int main() {
            Student stu4 = {1004, "赵六", 79.0};
            Student stu5;
            
            // 结构体变量直接赋值
            stu5 = stu4;
            
            printf("stu5：学号：%d，姓名：%s，成绩：%.1f\n", stu5.id, stu5.name, stu5.score);
            return 0;
        }
        ```

        **注意**：如果结构体包含指针成员（如`char *name`），直接赋值会导致两个变量的指针指向同一块内存，修改一个会影响另一个，此时需要手动实现深拷贝

        ###### 方法 4：通过指针给结构体成员赋值

        先定义结构体指针，通过 `->` 操作符访问成员并赋值（指针专用操作符）

        ```c
        int main() {
            Student stu6;
            Student *p = &stu6;  // 指针指向结构体变量
            
            // 指针访问成员用->
            p->id = 1005;
            strcpy(p->name, "钱七");
            p->score = 85.5;
            
            printf("学号：%d，姓名：%s，成绩：%.1f\n", p->id, p->name, p->score);
            return 0;
        }
        ```

        ###### 方法 5：使用 memcpy 函数赋值（字节级拷贝）

        `memcpy`是内存拷贝函数，可将一个结构体的内存数据直接拷贝到另一个结构体，效果等同于结构体直接赋值，适合需要手动控制内存拷贝的场景

        ```c
        int main() {
            Student stu7 = {1006, "孙八", 90.0};
            Student stu8;
            
            // memcpy(目标地址, 源地址, 拷贝字节数)
            memcpy(&stu8, &stu7, sizeof(Student));
            
            printf("stu8：学号：%d，姓名：%s，成绩：%.1f\n", stu8.id, stu8.name, stu8.score);
            return 0;
        }
        ```

    2. ##### 结构体操作

        1. 指针与赋值相关运算：`&` `*` `=`

            结构体的实例变量，每个成员都可以使用取地址、解引用和赋值运算

            与数组类似，结构体所述实例变量的地址值等于结构体第一个成员的地址值

        2. 成员访问操作：`.` `->` 

            结构体的实例变量可以使用原点成员运算符 `.` 和指针成员运算符 `->` 访问结构体成员变量

        3. 作为函数参数或者返回值

            - 结构体类型作为函数参数，如果直接传值会导致实参赋值形式化实参，当结构体成员哼多时会产生性能问题

                原则上，结构体类型作为函数参数传入时应采用传引用的方式（若需防修改可传厂指针），除非结构体成员明确且较少

            - 结构体指针作为函数的返回值，必须确保所指对象没有被释放，因此**不能返回指向函数中自动（普通局部）变量的指针**，应当返回：

                1. 返回指向函数中静态变量的指针 
                2. 返回指向函数中定义的字符串字面量的指针
                3. 返回指向全局变量或函数的指针
                4. 返回函数参数引用的对象及其关联对象的指针，如指向传入数组的元素，或指向传入结构体指针的成员
                5. 返回动态申请内存的指针

        4. 动态内存

            结构体类型数据多数需要动态管理且生命周期长，与指针配合，使用 `malloc()` 申请内存保存结构体对象/变量，在不需要时使用 `free()` 释放内存

4. #### 共用体

    共用体 `union` 也是一种派生数据类型，其中的所有成员共享同一个存储空间

    - 申请一个共用体与声明一个结构体的格式基本相同，关键词为 `union`
    - 共用体的基本操作
        - 实例变量的赋值
        - `&` 运算符取共用体实例变量的地址（实例变量的地址值和所有成员变量的地址值都相等）
        - 用原点成员运算符或指针运算符访问共用体的成员
        - **不能使用运算符 `==` 或 `!=` 比较两个共用体**

5. #### 枚举常量

    1. ##### 枚举类型的定义（核心概念）

        枚举（Enumeration，关键字：`enum`）是 C 语言中**用户自定义的基本数据类型**，用于将一组**离散、有限、具有语义关联的整型常量**集合化命名，其核心价值是替代 “魔法数字”（无语义的整型字面量，如 0、1、2），让代码的可读性和可维护性大幅提升

        **本质特征**：

        - 枚举常量（枚举成员）本质是**只读的整型常量**（默认类型为`int`）
        - 编译器会为未显式赋值的枚举常量自动分配整数值，默认从`0`开始，依次递增`1`
        - 枚举类型的变量仅能存储该枚举中定义的常量值（编译器不强制校验，但语义上应遵循）

    2. ##### 枚举常量的声明方式（分场景详解）

        枚举常量的声明有多种形式，适配不同的编程场景，以下按 “基础→进阶→常用” 的顺序讲解，所有示例均可直接编译运行

        ###### 方式 1：基础声明（标准形式）

        **语法格式**：

        ```c
        enum 枚举类型名 {
            枚举常量1,   // 默认值：0
            枚举常量2,   // 默认值：1（前一个值+1）
            ...
            枚举常量n    // 最后一个常量后可省略逗号
        };
        ```

        **示例**：

        ```c
        // 声明枚举类型enum Weekday，定义一周七天的枚举常量
        enum Weekday {
            MONDAY,    // 自动赋值0
            TUESDAY,   // 自动赋值1
            WEDNESDAY, // 自动赋值2
            THURSDAY,  // 自动赋值3
            FRIDAY,    // 自动赋值4
            SATURDAY,  // 自动赋值5
            SUNDAY     // 自动赋值6
        };
        ```

        **关键说明**：

        - `enum`是关键字，不可省略
        - `Weekday`是枚举类型名（符合 C 语言标识符规则，如不能以数字开头）
        - 枚举常量是全局 / 局部常量（取决于声明位置），**不可修改**（如`MONDAY = 10;`会编译报错）

        ###### 方式 2：显式指定枚举常量的值

        可手动为枚举常量赋值，未显式赋值的常量会继承 “前一个常量值 + 1”，支持非连续、重复赋值（语法合法，语义需谨慎）

        **语法格式**：

        ```c
        enum 枚举类型名 {
            枚举常量1 = 初始值,
            枚举常量2,       // 自动赋值：初始值+1
            枚举常量3 = 新值,
            枚举常量4        // 自动赋值：新值+1
        };
        ```

        **示例**：

        ```c
        // 显式指定部分枚举常量的值
        enum Season {
            SPRING = 1,  // 手动赋值1
            SUMMER,      // 自动赋值2（1+1）
            AUTUMN = 5,  // 手动赋值5
            WINTER       // 自动赋值6（5+1）
        };
        
        // 特殊场景：多个常量可赋值为同一值
        enum Status {
            SUCCESS = 0,
            FAIL = 1,
            ERROR = 1  // 与FAIL值相同，语法合法（语义需自洽）
        };
        ```

        ###### 方式 3：匿名枚举（无类型名）

        若仅需使用枚举常量，无需定义该类型的变量，可省略枚举类型名，称为 “匿名枚举”

        **语法格式**：

        ```c
        enum {
            枚举常量1,
            枚举常量2,
            ...
        };
        ```

        **示例**：

        ```c
        // 匿名枚举：仅定义颜色常量，无需类型名
        enum {
            RED,    // 0
            GREEN,  // 1
            BLUE    // 2
        };
        
        // 直接使用常量
        int color = GREEN; // 合法，color值为1
        ```

        **注意**：匿名枚举的常量作用域为当前代码块（全局 / 函数内），且无法定义该枚举类型的变量（无类型名）

        ###### 方式 4：声明类型时直接定义变量

        ```c
        enum 枚举类型名 {
            枚举常量1,
            枚举常量2,
            ...
        } 变量名1, 变量名2; // 多个变量用逗号分隔
        ```

        **示例**：

        ```c
        // 声明enum Color类型，同时定义变量c1、c2
        enum Color {
            BLACK,  // 0
            WHITE   // 1
        } c1, c2;
        
        // 后续使用变量
        c1 = BLACK;
        c2 = WHITE;
        ```

        ###### 方式 5：typedef 简化枚举类型名（实际开发最常用）

        枚举类型的完整引用形式是`enum 类型名`，使用`typedef`可将其简化为短名称，降低代码冗余，是工业级开发的主流写法

        **语法格式（两种写法）**：

        ```c
        // 写法1：匿名枚举 + typedef（推荐）
        typedef enum {
            枚举常量1,
            枚举常量2,
            ...
        } 简化类型名;
        
        // 写法2：先声明枚举类型，再typedef
        enum 原类型名 {
            枚举常量1,
            ...
        };
        typedef enum 原类型名 简化类型名;
        ```

        **示例**：

        ```c
        // 写法1（推荐）：typedef + 匿名枚举
        typedef enum {
            MALE,   // 0
            FEMALE  // 1
        } Gender;
        
        // 直接用简化类型名定义变量，无需写enum
        Gender person1 = MALE;
        Gender person2 = FEMALE;
        
        // 写法2：分步声明
        enum _Direction {
            LEFT,   // 0
            RIGHT,  // 1
            UP,     // 2
            DOWN    // 3
        };
        typedef enum _Direction Direction;
        
        // 使用简化类型名
        Direction dir = UP;
        ```

    3. ##### 枚举类型的使用注意事项

        1. **常量不可修改**：枚举常量是只读常量，赋值操作（如`MONDAY = 10;`）会触发编译错误
        2. **变量赋值规则**：枚举变量可赋值为任意整数（编译器不做范围校验），但语义上应仅使用枚举常量（如`enum Weekday day = 100;`语法合法，但无业务意义）
        3. **内存大小**：枚举变量的大小等同于`int`类型（通常 4 字节，取决于系统架构）
        4. **运算支持**：枚举常量可参与整型运算（如`int tomorrow = MONDAY + 1;`结果为 1）
        5. **作用域规则**：枚举常量的作用域与声明位置一致（全局 / 局部），同一作用域内不可定义同名枚举常量

    4. ##### 完整示例代码

        ```c
        #include <stdio.h>
        
        // 1. 基础枚举声明
        enum Weekday {
            MONDAY = 1,  // 显式赋值1
            TUESDAY,
            WEDNESDAY,
            THURSDAY,
            FRIDAY,
            SATURDAY,
            SUNDAY
        };
        
        // 2. typedef简化枚举
        typedef enum {
            SPRING = 1,
            SUMMER,
            AUTUMN,
            WINTER
        } Season;
        
        int main() {
            // 使用基础枚举类型定义变量
            enum Weekday today = WEDNESDAY;
            printf("今天是周%d\n", today); // 输出：今天是周3
        
            // 使用typedef简化后的枚举定义变量
            Season now = SPRING;
            printf("现在是第%d个季节\n", now); // 输出：现在是第1个季节
        
            // 枚举常量参与运算
            int tomorrow = today + 1;
        ```
