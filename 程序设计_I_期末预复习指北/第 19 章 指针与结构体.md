# 第 19 章 指针与结构体
1. #### 结构体内存布局

    1. ##### 结构体内存布局

        在内存中，结构体实例变量分配在一段连续的内存空间内，每个成员变脸依次被分配在后续的内存位置上

    2. ##### 字宽与内存对齐

        1. ###### 基础概念

            1. **字宽（word width）**

                指 CPU 一次从内存读取 / 写入的位数：

                - 32 位计算机的字宽为 4 字节（32 位），因此其内存访问地址默认是 4 的倍数

            2. **内存对齐（alignment）**

                让数据按 “字宽边界” 存放（即使浪费少量内存），以提升 CPU 读写效率

                例如 32 位系统中，整数变量的地址通常是 4 的倍数

            3. **内存不对齐的影响**

                对于 32 位字宽的计算机，每次访问内存的地址总是 4 的倍数

                若数据（如整数）存放在非字宽倍数的地址，CPU 需通过多条指令 / 多个微指令周期完成读写和拼接，导致数据处理性能大幅下降

        2. ###### 对齐控制指令：`#pragma pack(N)`

            - 作用：控制后续定义的结构体、共用体的**最大对齐值**（N 的取值为 {1,2,4,8,16,32}）
            - 默认规则：32 位系统下默认 `N=4`

        3. ###### 基本数据类型的对齐规则

            某基本数据类型的起始地址需满足：

            - 若该类型所占字节数 **≥** `#pragma pack(N)`的 N，则起始地址是 N 的倍数
            - 若该类型所占字节数 **<** N，则起始地址是其自身字节数的倍数

        4. ###### 结构体（`struct`）的对齐规则

            结构体的对齐需分 3 步执行：

            1. **成员的起始地址**：按 “基本数据类型对齐规则” 确定每个成员的起始地址
            2. **结构体的对齐值**：`min(所有成员的对齐值的最大值, #pragma pack(N)的N)`
            3. **结构体的总大小**：需是其对齐值的整数倍（不足则填充字节）

            - 结构体对齐示例

            对于结构体：

            ```c
            typedef struct {
                char a[3];  // 1字节/元素，共3字节
                int b;      // 4字节
                short c;    // 2字节
            } packed_struct;
            ```

            示例 1：`#pragma pack(1)`

            - 成员地址分配：
                - `a[3]`：起始地址 0，占地址 0 - 2
                - `b`：4 字节 $\ge$ N = 1，起始地址 3（1 的倍数），占地址 3 ~ 6
                - `c`：2 字节 $\ge$ N = 1，起始地址 7（1 的倍数），占地址 7 ~ 8
            - 结构体对齐值：`min(成员最大对齐值4, N=1)=1`
            - 总大小：9（地址 0-8），是 1 的倍数 → `sizeof(packed_struct) = 9`

            示例 2：`#pragma pack(4)`

            - 成员地址分配：
                - `a[3]`：占地址 0 - 2
                - `b`：4 字节 $\ge$ N = 4，需从 4 的倍数地址开始，故填充 1 字节（地址 3），`b`占地址 4 ~ 7
                - `c`：2 字节 < N = 4，从 2 的倍数地址 8 开始，占地址 8 ~ 9
            - 结构体对齐值：`min(成员最大对齐值4, N=4)=4`
            - 总大小：当前占 10 字节（地址 0-9），需是 4 的倍数，故填充 2 字节（地址 10-11） → `sizeof(packed_struct)=12`

            示例 3：`#pragma pack(2)`

            - 成员地址分配：
                - `a[3]`：占地址 0 - 2
                - `b`：4 字节 $\ge$ N = 2，需从 2 的倍数地址开始（地址 3 非 2 的倍数，填充 1 字节到地址 3），`b `占地址 4 ~ 7
                - `c`：2 字节 = N= 2，从地址 8 开始，占地址 8 ~ 9
            - 结构体对齐值：`min(4,2)=2`
            - 总大小：10 字节（地址 0 ~ 9），是 2 的倍数 → `sizeof(packed_struct)=10`

        5. ##### 共用体（`union`）的对齐规则

            共用体的所有成员**共享同一块内存**，其对齐与大小规则：

            1. 对齐值：`min(所有成员的对齐值的最大值, #pragma pack(N)的N)`
            2. 总大小：是对齐值的整数倍，且不小于**最大成员的大小**

            - 共用体对齐示例

            对于共用体：

            ```c
            typedef union {
                char a[3];  // 大小3字节
                int b;      // 大小4字节
                short c;    // 大小2字节
            } packed_union/unpacked_union;
            ```

            示例 1：`packed_union`（`#pragma pack(1)`）

            - 最大成员大小：4（`int b`）
            - 对齐值：`min(4,1)=1`
            - 总大小：4（是 1 的倍数，且不小于 4） → `sizeof(packed_union)=4`

            示例 2：`unpacked_union`（`#pragma pack(4)`）

            - 最大成员大小：4
            - 对齐值：`min(4,4)=4`
            - 总大小：4（是 4 的倍数，且不小于 4） → `sizeof(unpacked_union)=4`

2. #### 位域与内存布局

    1.  位域的基本概念

        位域是 C 语言中结构体的扩展特性，用于为结构体成员分配**指定长度的二进制位**存储空间，其核心价值是实现内存的精细化管理，方便按位访问数据（典型场景：硬件寄存器配置、协议数据帧字段解析等）

    2. 位域的定义语法

        在结构体中，位域成员的声明格式为：

        ```c
        struct 结构体名 {
            类型 成员名: 位宽;
        };
        ```

        - 语法要素说明

            - **类型**：仅支持以下类型：
                - 整数类型（如`int`）
                - 无符号整数类型（如`unsigned int`）
                - 布尔类型（`_Bool`）

            - **位宽**：非负整数常量表达式，需满足 `0 < 位宽 ≤ 对应类型的二进制位数`（例如：`unsigned int`通常占 4 字节 / 32 位，其位宽不能超过 32）

    3. 位域的赋值与数值截断

        当赋值的数值超出位域位宽的表示范围时，会发生**隐式截断**：仅保留数值的**低位部分**，高位部分被丢弃，最终值为截断后的结果

        ```c
        struct A {
            unsigned int t: 2; // 位宽2，无符号，可表示范围：0~3
        };
        struct A a = {2}; // 赋值2（在范围内），a.t = 2
        a.t = 3;          // 赋值3（在范围内），a.t = 3
        a.t = 4;          // 4的二进制为100，截断低2位为00，故a.t变为0
                          // 编译器会提示“Implicit truncation from 'int' to bit-field”警告
        ```

    4. 位域的内存布局（打包与对齐）

        位域的内存分配遵循**打包规则**与**对齐规则**，以平衡内存利用率与对齐要求

        4.1 打包规则

        连续声明的位域会被 “打包” 到同一个**整数包**中（“包” 的大小等于位域对应整数类型的大小，例如`int`对应 4 字节包），直到当前包的剩余空间不足以容纳下一个位域

        4.2 对齐规则

        - 位域的对齐以对应整数类型的对齐值为准
        - 第一个位域必须按对应整数类型对齐
        - 一个 “包” 的大小不超过对应整数类型的大小

        4.3 示例解析

        ```c
        struct B {
            unsigned t1: 10; // 占10位
            unsigned t2: 11; // 占11位，累计21位
            unsigned t3: 11; // 占11位，累计32位（恰好填满一个int包）
        };
        // sizeof(struct B) = 4（int占4字节/32位）
        ```

        其内存布局（以 32 位`int`为例）：

        | 31~21（11 位） | 20~10（11 位） | 9~0（10 位） |
        | -------------- | -------------- | ------------ |
        | t3             | t2             | t1           |

    5. 特殊位域

        C 语言支持两种特殊位域，用于灵活控制内存布局：

        5.1 匿名位域

        格式：`类型 : 位宽;`（无成员名），作用是**跳过（占用）指定数量的二进制位**，不对应具体的成员变量

        5.2 0 宽度位域

        格式：`类型 : 0;`，作用是标识**当前整数包已填满**，后续位域会被分配到新的整数包中（新包仍按对应整数类型对齐）

    6. 位域的使用限制与建议

        - **限制**：位域成员**不能直接求地址**（`&`运算符无法作用于位域，因为位域是整数的部分位，并非独立内存单元）
        - **建议**：将位域结构体与对应整数类型放在`union`中，既可以通过位域访问各个位段，也可以通过`union`的整数成员获取整个内存单元的地址或值（典型用于硬件寄存器操作）

    7. 位域案例分析

        ```c
        #include<stdio.h>
        
        struct BF10 { int a:4; } bit_field1;
        struct BF11 { int a:4, :2, b:5; } bit_field2;
        struct BF20 { int a:4, :2; int b:27; } bit_field3;
        struct BF21 { int a:4, :2, :0; int b:4; } bit_field4;
        
        union { int i; struct BF11 bf11; } u1 = { .i=0x5a };
        union { int i[2]; struct BF21 bf21; } u2 = { .i={0x5a, 0x5a} };
        
        int main() {
            printf("bit_field1 size %d, start = %p\n",sizeof(bit_field1),&bit_field1);
            printf("bit_field2 size %d, start = %p\n",sizeof(bit_field2),&bit_field2);
            printf("bit_field3 size %d, start = %p\n",sizeof(bit_field3),&bit_field3);
            printf("bit_field4 size %d, start = %p\n",sizeof(bit_field4),&bit_field4);
            
            printf("%x,%x\n",u1.bf11.a,u1.bf11.b);
            printf("%x,%x\n",u2.bf21.a,u2.bf21.b);
        }
        
        ```

        - 程序运行结果

            ```
            bit_field1 size 4, start = 0x102b58010
            bit_field2 size 4, start = 0x102b58014
            bit_field3 size 8, start = 0x102b58018
            bit_field4 size 8, start = 0x102b58020
            fffffffa,1
            fffffffa,fffffffa
            ```

        - 程序分析

            1. 逐结构体解析：内存布局与大小计算

                先分析 4 个结构体的定义、内存布局和 `sizeof` 结果（默认平台：32 位 / 64 位系统，`int` 占 4 字节 / 32 位）。

                1. `struct BF10`

                ```c
                struct BF10 {
                    int a:4;  // 有符号位域，占用4位
                } bit_field1;
                ```

                - **内存布局**：`a` 是 `int` 类型位域，占用第一个 `int` 存储单元（32 位）的低 4 位，剩余 28 位闲置。
                - **大小计算**：仅需 1 个 `int` 存储单元 → `sizeof(bit_field1) = 4` 字节。

                2. `struct BF11`

                ```c
                struct BF11 {
                    int a:4, :2, b:5;  // a:4位 → 无名填充:2位 → b:5位
                } bit_field2;
                ```

                - **内存布局**：所有成员都是 `int` 类型，优先挤在同一个 4 字节单元里：

                    - `a`：占用位 0~3（4 位）；

                    - 无名位域 `:2`：占用位 4~5（2 位，仅填充不可访问）；

                    - `b`：占用位 6~10（5 位）；

                        总占用位数：4+2+5=11 位 < 32 位，无需新增存储单元。

                - **大小计算**：仅需 1 个 `int` 存储单元 → `sizeof(bit_field2) = 4` 字节。

                3. `struct BF20`

                ```c
                struct BF20 {
                    int a:4, :2;  // a:4位 → 无名填充:2位
                    int b:27;     // 27位
                } bit_field3;
                ```

                - **内存布局**：
                    - 前两个位域（`a:4 + :2`）占用 6 位，剩余 32-6=26 位；
                    - `b:27` 需要 27 位，26 位不足以容纳，因此 `b` 会分配**新的 `int` 存储单元**；
                - **大小计算**：需要 2 个 `int` 存储单元 → `sizeof(bit_field3) = 4×2 = 8` 字节。

                4. `struct BF21`

                ```c
                struct BF21 {
                    int a:4, :2, :0;  // a:4位 → 填充:2位 → :0强制新单元
                    int b:4;          // 4位（新单元）
                } bit_field4;
                ```

                - **内存布局**：
                    - `a:4 + :2` 占用第一个 `int` 单元的 6 位；
                    - `:0` 是宽度为 0 的无名位域，强制 `b` 从**新的 `int` 单元**开始；
                    - `b:4` 占用第二个 `int` 单元的低 4 位；
                - **大小计算**：需要 2 个 `int` 存储单元 → `sizeof(bit_field4) = 4×2 = 8` 字节。

            2. 联合的定义与初始化解析

                联合的核心是 “内存共享”，下面分析 2 个联合的内存布局和初始化值：

                1. `union u1`

                ```c
                union {
                    int i;          // 4字节
                    struct BF11 bf11;  // 4字节（与i共享内存）
                } u1 = {.i=0x5a};  // 初始化i为0x5a（十进制90）
                ```

                - 联合大小：4 字节（`int` 和 `BF11` 都是 4 字节）；

                - 内存赋值：`i=0x5a` → 4 字节内存中存储的二进制（32 位，小端模式，低位在前）：

                    ```plaintext
                    位31~8：00000000 00000000 00000000
                    位7~0： 0101 1010 （0x5a的8位二进制）
                    ```

                    简化为关键位（位 0~10）：

                    | 位 10 | 位 9 | 位 8 | 位 7 | 位 6 | 位 5 | 位 4 | 位 3 | 位 2 | 位 1 | 位 0 |
                    | ----- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
                    | 0     | 0    | 0    | 0    | 1    | 0    | 1    | 1    | 0    | 1    | 0    |

                2. `union u2`

                ```c
                union {
                    int i[2];       // 8字节（2个int）
                    struct BF21 bf21;  // 8字节（与i共享内存）
                } u2 = {.i={0x5a,0x5a}};  // 初始化i[0]=0x5a，i[1]=0x5a
                ```

                - 联合大小：8 字节（`int[2]` 和 `BF21` 都是 8 字节）；
                - 内存赋值：
                    - 低 4 字节（i [0]）：0x5a → 二进制同 u1；
                    - 高 4 字节（i [1]）：0x5a → 二进制同 u1；
                - `BF21` 的布局：`a` 占用低 4 字节的位 0~3，`b` 占用高 4 字节的位 0~3。

            3. printf 输出结果解析（核心重点）

                1. 输出结构体大小和地址

                ```c
                printf("bit_field1 size %d, start = %p\n", sizeof(bit_field1),&bit_field1);
                // 输出：bit_field1 size 4, start = 0x102b58010
                
                printf("bit_field2 size %d, start = %p\n", sizeof(bit_field2),&bit_field2);
                // 输出：bit_field2 size 4, start = 0x102b58014
                
                printf("bit_field3 size %d, start = %p\n", sizeof(bit_field3),&bit_field3);
                // 输出：bit_field3 size 8, start = 0x102b58018
                
                printf("bit_field4 size %d, start = %p\n", sizeof(bit_field4),&bit_field4);
                // 输出：bit_field4 size 8, start = 0x102b58020(十六进制)
                ```

                - 地址是变量的内存地址，每次运行不同，无需关注具体值；
                - 大小结果固定：4、4、8、8（符合前文的大小计算规则）。

                2. 输出 u1 的 `bf11.a` 和 `bf11.b`

                ```c
                printf("%x,%x\n",u1.bf11.a,u1.bf11.b);
                ```

                步骤 1：计算 `u1.bf11.a`（int a:4，位 0~3）

                - 位 0~3 的二进制：`1010`（从表格中取位 0=0、位 1=1、位 2=0、位 3=1）；
                - `int a:4` 是**有符号位域**，4 位有符号数的最高位是位 3（值为 1），表示负数；
                - 补码转换：`1010` 是补码 → 原值 = -8 + 2 = -6；
                - printf("%x", a)：`a` 会被提升为 32 位 int，-6 的补码是 `0xFFFFFFFA` → 输出 `fffffffa`。

                步骤 2：计算 `u1.bf11.b`（int b:5，位 6~10）

                - 位 6~10 的二进制：`00001`（位 6=1，位 7~10=0）；
                - `int b:5` 是有符号位域，最高位是位 10（值为 0），表示正数；
                - 原值 = 1 → printf ("% x", b) 输出 `1`。

                最终输出：`fffffffa,1`

                3. 输出 u2 的 `bf21.a` 和 `bf21.b`

                ```c
                printf("%x,%x\n",u2.bf21.a,u2.bf21.b);
                ```

                步骤 1：计算 `u2.bf21.a`（int a:4，低 4 字节的位 0~3）

                - 低 4 字节是 0x5a → 位 0~3 二进制 `1010` → 有符号值 - 6；
                - 提升为 32 位 int 后补码 `0xFFFFFFFA` → 输出 `fffffffa`。

                步骤 2：计算 `u2.bf21.b`（int b:4，高 4 字节的位 0~3）

                - 高 4 字节是 0x5a → 位 0~3 二进制 `1010` → 有符号值 - 6；
                - 提升为 32 位 int 后补码 `0xFFFFFFFA` → 输出 `fffffffa`。

                最终输出：`fffffffa,fffffffa`

3. #### 结构体指针与链表

    结构体类型在定义时不能嵌套自身类型，但可以通过成员变量应用自身类型（结构体指针）实现**自引用结构体**

    利用自引用结构体定义链表、树等更加复杂的数据结构

    ```c
    // 定义一个链表节点
    typedef struct Node {
        int val;
        struct Node *next;
    }node;
    
    // 定义一个树的结点
    struct TreeNode {
        int val;
        struct TreeNode *left;
        struct TreeNode *right;
    }
    ```

    |          | 数组                                       | 链表                             | 备注           |
    | -------- | ------------------------------------------ | -------------------------------- | -------------- |
    | 定义     | 同类元素，连续存放，固定长度               | 同类元素，离散存放，动态长度     | 节点包含指针域 |

    | 插入删除 | 在尾部插入或删除方便其他位置会导致元素迁移 | 方便任意位置插入和删除           |                |
    | 元素查找 | 有序序列可二分查找                         | 只能顺序查找                     |                |
    | 空间     | 少                                         |                                  |                |
