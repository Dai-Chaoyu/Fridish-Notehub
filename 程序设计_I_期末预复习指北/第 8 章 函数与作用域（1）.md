# 第 8 章 函数与作用域（1）
- 函数的概念：函数是一个初等表达式，方便以模块化的形式进行编程

- 函数的声明与定义
    - 函数的声明需写出函数名、输入参数和输出类型，也叫做函数的接口信息
    - C 语言中，函数值类型的定义可以缺省，此时**函数返回值的隐含类型是 `int`**
    - 函数的定义需要给出一个实现了函数的内部逻辑的复合语句
    - C 程序与函数：
        - 程序必须有一个`main`函数
        - 函数不能重名
        - 函数应该先声明，后实现
    - 函数的形参与实参
        - 函数在声明和定义时用的参数成为形式参数（形参）
            - 参数定义时由于没有具体值，只是一个符号或可存储特定数值的空间
            - 声明时可仅声明参数类型
            - 定义时必须给出形式参数名称，便于函数体使用
        - 函数在使用时实际体态形式参数的值为实际参数
            - 实际参数与声明的形式必须数量相同，类型兼容
            - 如果实参形参类型兼容但不一致，则按照初始化规则发生强制转换
    
- 函数的调用
    - 根据是否有参数以及是否返回值，已经将函数分为四种
    - 函数参数默认按值传递，函数内无论对变量做什么操作不影响原本的变量
    - 可以通过引用传递实现函数内对原本变量的修改
    - 函数遇到`return` 语句或函数块执行完毕认为是函数表达式完成求值
    
- 常用数学函数
    - 在标头 `<stdlib.h>` 定义
      - `int abs(int n);`：返回整数 `n` 的绝对值

    - 定义于头文件 `<math.h>`
      - `double fabs(double arg);`：返回双精度浮点数 `arg` 的绝对值
      - `double exp(double arg);`：计算自然常数 `e` 的 `arg` 次幂（即 \( e^{\text{arg}} \)）
      - `double log(double arg);`：计算 `arg` 的自然对数（以 `e` 为底）
      - `double log10(double arg);`：计算 `arg` 的常用对数（以 `10` 为底）
      - `double pow(double base, double exponent);`：计算 `base` 的 `exponent` 次幂（即 $\text{base}^{\text{exponent}} $）
      - `double sqrt(double arg);`：计算 `arg` 的平方根（要求 `arg ≥ 0`）
      - `double sin(double arg);`：计算弧度值 `arg` 的正弦值
       - 三角函数系列还有： `cos`：计算弧度值的余弦值；`tan`：计算弧度值的正切值；`asin`：计算反正弦值；`acos`：计算反余弦值；`atan`：计算反正切值
      - `double ceil(double arg);`：返回大于或等于 `arg` 的最小整数值（向上取整）
      - `double floor(double arg);`：返回小于或等于 `arg` 的最大整数值（向下取整）
    
- 变量的作用域：能够访问该变量的范围
    - 根据作用域的范围，变量可以分为三类：
    
        | 位置                 | 种类     | 初始化                   | 生命周期       |
        | -------------------- | -------- | ------------------------ | -------------- |
        | 在函数或代码块里     | 局部变量 | 必须手动初始化           | 整个函数（块） |
        | 在所有函数外面       | 全局变量 | 自动初始化为 0           | 整个程序       |
        | 在函数的参数列表里面 | 形式参数 | 根据传入参数值自动初始化 | 整个函数（块） |
    
- 局部变量
    - 在语句或语句块内定义的变量，又称为**自动变量**，当语句或语句块执行结束，所有自动变量被释放
    - 局部变量不会自动初始化，必须手动初始化
    
- 变量重名的屏蔽：当不同作用域的变量重名时，遵循 **“内层作用域屏蔽外层作用域”的规则，即优先使用 “离当前代码最近的作用域中定义的变量”**
