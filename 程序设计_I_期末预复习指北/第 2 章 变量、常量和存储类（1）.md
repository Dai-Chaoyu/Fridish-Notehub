# 第 2 章 变量、常量和存储类（1）
-  变量类型（Variable Tyepes）
    1. 整数：自然数（unsigned）、有符号数（signed）
    2. 实数：浮点数（float）、双精度数（double）
    3. 用`char`, `short`, `int`, `long` 存储不同范围的整数，而用`float`, `double` 存储不同精度的实数
    4. 常见的基本变量类型如下所示：
    
    | 类型             | 占用字节 | 数值范围                             |
    | ---------------- | -------- | ------------------------------------ |
    | （长）整形       | 4        | $[\ -2^{31}，2^{31}-1\ ]$            |
    | 无符号（长）整形 | 4        | $[\ 0，2^{32}-1\ ]$                  |
    | 短整形           | 2        | $[\ -2^{15}，2^{15}-1\ ]$            |
    | 无符号短整型     | 2        | $[\ 0，2^{16}-1\ ]$                  |
    | 长长整形         | 8        | $[\ -2^{63}，2^{63}-1\ ]$            |
    | 无符号长长整形   | 8        | $[\ 0，2^{64}-1\ ]$                  |
    | 字符型           | 1        | $[\ -2^7，2^7-1\ ]$                  |
    | 无符号字符型     | 1        | $[\ 0，2^8 -1\ ]$                    |
    | 单精度型         | 8        | $[\ -3.4×10^{38} ，3.4×10^{38}\ ]$   |
    | （长）双精度型   | 8        | $[\ -1.7×10^{308} ，1.7×10^{308}\ ]$ |

- `printf` 函数常见的转换说明

    | 转换说明 | 输出                           |

    | %c       | 单个字符                       |
    | %d       | 有符号十进制整数               |
    | %u       | 无符号十进制整数               |
    | %f       | 十进制浮点数                   |
    | %e(E)    | 以科学计数法输出浮点数         |
    | %o       | 无符号八进制整数               |
    | %x       | 无符号十六进制整数（字母小写） |

- `printf` 函数常见的转换说明修饰符

    | 标志修饰符   | 含义                                                         |
    | ------------ | ------------------------------------------------------------ |
    | **-**        | 强制左对齐                                                   |
    | **+**        | 强制显示正负号                                               |
    | **（空格）** | 在正数前面加空格，比+的优先级高                              |
    | **#**        | 对特定转换符添加前缀或强制显示小数点：<br>%#o —— 八进制加前缀 0（如 012）<br>%#x —— 十六进制加前缀 0x（如 0xab）<br>%#f —— 浮点数强制显示小数点 |
    | **0**        | 用 0 填充右对齐的空缺（默认使用空格填充，与 - 互斥）         |
| 类型       | 内容                  | 含义                                                         |
| ---------- | --------------------- | ------------------------------------------------------------ |
| 宽度修饰符 | 数字                  | 指定输出的最小字段宽度，如果实际输出长度小于宽度，会默认用空格填充（可与标志修饰符 0 搭配使得用 0 填充） |
| 精度修饰符 | `.` + 数字            | 对于整数，指定有效数字位数，不足补 0，超出按实际输出<br>对于浮点数，指定小数点后保留的位数（四舍五入）<br>对于字符串，指定最大输出的字符数，若超过则截断 |
| 长度修饰符 | l <br>ll <br>h <br>hh | 将变量类型转为长类型（ld —— long int）<br>将变量类型转换为长长类型（lld —— long long int)<br>将变量类型转为短类型（hi —— short int）<br>将整形转换为字符型（hhu —— unsigned char） |

- `printf` 函数特殊字符的输出：
| 特殊字符       | 含义/作用                  | 转义序列 | 输出效果示例                          |
|----------------|---------------------------|----------|---------------------------------------|

| `\v`           | 垂直制表符（垂直方向对齐） | `\v`     | 输出后垂直跳格（终端中效果有限）      |

4. 常量
    - 常量可以是任何的基本数据类型，也可以是复合数据类型
        - 整数常量：默认是十进制，也可以是二进制（前缀 0b，C99 不支持）、八进制（前缀 0）或十六进制（前缀 0x），用后缀u/U 标识无符号数和 l/L 标识长型
        - 浮点常量：使用小数形式（整数部分+小数点+小数部分）或者指数形式（尾数部分+e/E+整数指数部分）表示
        - 字符常量：直接表示（' 空格或大部分可见图形字符 '）或转义符表示（' \字符、八进制数、十六进制数 '）
        - 字符串常量：“这是一个字符串”
    - 常量的定义和声明
        - 使用`#define` 预处理器：`#define pi 3.14`
        - 使用`const` 关键字：`const float pi = 3.14; `
5. 存储类
    - 存储类定义了 C 程序中变量/函数的作用域和生命周期
    - `auto` 存储类：是所有局部变量默认的存储类，现支持自动类型推断
    - `register` 存储类：定义存储在寄存器中而不是 RAM 中的局部变量（不可使用&取地址运算符）
    - `static` 存储类：使变量的生命周期变成程序结束为止
        - 用`static` 修饰全局变量，则全局变量的作用域**从原来的整个程序变为静态全局变量所在的文件内部**
        - 用`static` 修饰局部变量，作用域不变
    - `extern` 存储类：用于提供一个全局变量的引用，使变量对所有程序都是可见的
