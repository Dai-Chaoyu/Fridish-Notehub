# 第 5 章 选择结构
- 语句的类型
    - 复合语句
    - 表达式语句
    - 选择语句
    - 循环语句
- 布尔表达式：表达式值类型属于`{0,1}` 的表达式成为布尔表达式
    - C 语言内置支持布尔常数`1,0` 和布尔类型`_Bool`（非零值转为 1,否则转为 0）
    - 通过`stdbool.h` 可拓展：常数`true = 1` `false = 0` , 类型`bool`
    - 可以发现，在 C 语言中，`true` `false` `bool` 不是关键字，可以再定义
- If 语句
    - If 语句中的表达式是布尔表达式，若不是则发生强制转换（传统上，非零值表示条件成立）
    - 在 If 语句的嵌套中，**else 总是与它前面最近的 If 配对**
- Switch 语句
    - Switch 结构中的表达式应为整数类型（包括字符类型），不能为浮点型或变量
    - 如果表达式值与每一个`case` 语句中的常量相同，流程就跳转到此分支并执行后面的语句，**直到`break` 语句跳出 Switch 结构**
    - 如果没有与 Switch 表达式相匹配的 case 常量则执行 default 语句
- 三目运算符：`() ? () : () ` ，结合方向是从右至左
