# 第 1 章 c 语言概述
- #### 机器语言、汇编语言与高级语言

- #### 程序的编译过程

    1. 预处理阶段：处理源代码`.c`文件中以#开头的预处理指令（如`#include`   `#define`等），生成预处理之后的源代码`.i`文件
    2. 编译阶段：将预处理之后的`.i`文件转换为汇编语言代码`.s`文件
    3. 汇编阶段：编译器（Assembler）将汇编代码`.s`转换为机器能够直接识别的二进制目标`.o (Linux)` `.obj (Windows)`文件
    4. 链接阶段：连接器（Linker）将多个目标文件（及所需的库文件）合并，生成可执行文件`.exe`

- #### C 语言程序出错的情况

    程序出错的情况可以主要分为三大类，从错误被发现的阶段和性质来看，分别是：编译错误、运行时错误、逻辑错误。这三类错误的表现形式、排查难度和常见原因都有明显区别。

    1. ##### 编译错误（语法 / 静态错误）

    这类错误是编译器在将源代码转换成机器码时就能发现的错误，程序连运行的机会都没有。

    - **本质**：违反了 C 语言的语法规则，编译器无法理解你的代码。
    - **常见原因**：
        - 语法书写错误：少写分号`;`、括号不匹配（`()`/`{}`/`[]`）、关键字拼写错误（如把`int`写成`Int`）。
        - 声明 / 定义问题：使用未声明的变量、重复定义同一个变量、数据类型不匹配（如用`%d`输出字符串）。
        - 预处理错误：头文件包含错误（如`#include <stdio.h>`写成`#include "stdio.h"`且路径不对）、宏定义语法错误。
        - 修改`const`变量：`const int a = 10; int *p = (int*)&a; *p = 20;`，`const`变量理论上只读，强制修改会导致不可预测的结果（部分编译器会优化掉 a 的存储，修改后读取仍为 10）。
    - **特点**：编译器会明确提示错误行号和原因（如`error: expected ';' before '}' token`），新手只要对照提示修改即可，排查难度最低。

    ##### 2. 运行时错误

    程序能成功编译，但运行过程中出现崩溃、卡死或异常输出，甚至直接终止。

    - **本质**：代码语法合法，但执行了非法操作，操作系统或运行环境会终止程序。
    - **常见原因**：
        - 输入输出错误：读取文件时文件不存在、向只读文件写入数据、输入数据类型与程序预期不符（如要求输入数字却输入字符串）。
        - 资源耗尽：申请过多内存导致内存不足、死循环占用全部 CPU 资源。
        - 内存相关操作：解引用空指针 / 野指针、访问已释放的内存、**多次释放同一内存**
    - **特点**：编译无报错，运行时才出现问题；部分错误会弹出段错误（Segmentation fault）、浮点异常（Floating point exception）等提示，排查需要结合调试工具（如 gdb）定位出错位置。

    ##### 3. 未定义行为

    1. 内存相关的未定义行为：**访问数组越界**、**修改字符串常量**：`char *str = "hello"; str[0] = 'H';`、**使用未初始化的自动（局部）变量：`int a; printf("%d", a);`**
    2. 运算相关的未定义行为：**整数溢出**、**除数为 0**、**顺序点前修改同一变量多次**（`int a = 1; int b = a++ + ++a;`）
    3. 函数 / 流程相关的未定义行为：**函数参数类型不匹配**（`void func(int a); func("hello");`，编译器可能不报错）、**跳转跳过变量初始化**（`goto label; int a = 10; label: printf("%d", a);`）
    4. 运算错误：除数为 0（`int a = 1/0;`）、整数溢出（如`int a = 2147483647 + 1;`超出 int 范围）、**非法类型转换**。
    5. 浮点数的非数值情形引发的错误：浮点数的运算结果为 Nan（Not a Number）时，进一步运算可能导致未定义行为

    ##### 4. 逻辑错误

    程序能编译、能运行，但输出结果不符合预期。

    - **本质**：代码语法和运行操作都合法，但算法逻辑、业务逻辑设计错误。
    - **常见原因**：
        - 条件判断错误：把 `==` 写成 `=`、逻辑运算符用错（如 `&&` 和 `||` 混淆）、边界条件考虑不全（如循环少执行一次）。
        - 变量使用错误：变量初始化错误（如未初始化就参与运算）、变量作用域理解错误（如局部变量覆盖全局变量）。
        - 算法逻辑错误：排序算法思路错误、循环次数计算错误、数学公式实现错误（如把`a+b`写成`a*b`）。
    - **特点**：无任何报错信息，只能通过打印中间变量、调试逐行执行等方式，对比 “预期结果” 和 “实际执行结果” 来定位问题。
