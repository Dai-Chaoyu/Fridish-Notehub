# 第 13 章 指针与数组
1. 指针的概念：指针是变量，它可以**保存内存中指定类型数据的地址**

2. 指针的定义与运算

    - 指针变量声明与定义的一般形式为：

        ```plaintext
        变量类型 *指针变量名[=初始地址]
        ```

        ```c
        int    *p1;  /* 整型指针 */
        double *p2;  /* 双精度浮点型指针 */
        char   *p3;  /* 字符型指针*/
        ```

        注意：

        - 声明语句中，星号 (`*`) 是用来指定一个变量是指针
        - 指针的值是 32 位或 64 位整数作为地址，可以使用 `p` 或 `x` 作为打印指示符类型
        - 指针的变量类型，表示指针地址值对应的内存位置存储的数据的类型
        - 指针变量，可以使用 `extern`、`static`、`auto`、`register` 存储类型修饰

    - 指针的运算

        1. 取址运算 `&`

            `&左值表达式` 可以得到该表达式对象的地址值

            ```c
            int *intp = &i;
            ```

        2. 解引用运算 `*`

            `*指针变量` 在表达式中访问其所指向的对象 / 变量或函数

            ```c
            *intp = 3;  //作为左值表达式
            j=*intp;    //作为右值表达式
            ```

        3. 指针常量 `NULL`

            `NULL` 指针是一个定义在标准库中的值为零的常量

            当变量声明的时候，如果没有确切的地址可以赋值，为指针变量赋一个 NULL 值，表示当前指针空闲

3. 指针算术、比较运算符

    给定 `int *p,*q,i;` 指针算术、比较运算如下表

    |          | 语法             | 说明                       | 等价语法 |
    | -------- | ---------------- | -------------------------- | -------- |
    | 算术运算 | `q - p`          | p，q 指针之间 int 元素个数 |          |
    |          | `p++` 或 `++p`   | p 指向下一个 int 元素      |          |
    |          | `p--` 或 `--p`   | p 指向上一个 int 元素      |          |
    |          | `p + i`          | 指向后第 i 个 int 元素     | `&p[i]`  |
    |          | `p - i`          | 指向后前 i 个 int 元素     | `&p[-i]` |
    | 比较运算 | `p==q` 或 `p!=q` | p，q 是否有相同地址        |          |
    |          | `p>q` 或 `p>=q`  | p 指针是否高于 q 的地址    |          |
    |          | `p<q` 或 `p<=q`  | p 指针是否低于 q 的地址    |          |

4. 指针与数组

    - 如果要使指针指向一个数组，必须调用**动态内存分配函数**，在堆区申请指定大小的连续内存

        1. `malloc`

            - **功能**：堆区分配指定字节数的连续内存，内存内容未初始化（随机值）。

            - **调用**：`void *malloc(size_t size)`；参数为「总分配字节数」；返回内存地址（失败返`NULL`）；需手动`free`释放。

        2. `calloc`

            - **功能**：堆区分配多元素连续内存，自动将所有字节初始化为 0。

            - **调用**：`void *calloc(size_t num, size_t size)`；参数为「元素个数」「单个元素字节数」；返回地址（失败返`NULL`）；需手动`free`释放。

        3. `realloc`

            - **功能**：调整堆区已分配内存（`malloc/calloc/realloc`分配）的大小（扩容 / 缩容）。

            - **调用**：`void *realloc(void *ptr, size_t size)`；参数为「原内存指针」「新总字节数」；返回新地址（失败返`NULL`，原内存保留）；需手动`free`，勿直接用原指针接收返回值。

        4. `alloca`

            - **功能**：栈区分配临时内存，函数结束后自动回收，无需手动释放。

            - **调用**：`void *alloca(size_t size)`；参数为「分配字节数」；非标准函数（移植性差）；栈空间小，勿分配大内存（易溢出）。

    | 函数    | 核心特点                       | 内存区域 | 是否需手动 free | 初始化           |
    | :------ | :----------------------------- | :------- | :-------------- | :--------------- |
    | malloc  | 基础动态分配                   | 堆区     | 是              | 否               |
    | calloc  | 分配多元素内存，自动初始化为 0 | 堆区     | 是              | 是（0）          |
    | realloc | 调整已分配内存的大小           | 堆区     | 是              | 新增区域未初始化 |
    | alloca  | 快速分配，自动回收             | 栈区     | 否              | 否               |

    - 对于 `T *p` 和 `T a[N]`，我们用下表对比它们

    | 指针 p                         | 数组 a                               | 备注                                                         |
    | ------------------------------ | ------------------------------------ | ------------------------------------------------------------ |
    | 下标运算 p [i]                 | 下标运算 a [i]                       | 设 p == a, p [i] 和 a [i] 是同一对象                         |
    | 算术运算 p + i                 | 算术运算 a + i                       | 设 p == a, p+i 和 a+i 是相同指针                             |
    | 解引用 *p                      | 解引用 *a                            | 设 p == a, 解引用对象是 a [0]                                |
    | p 是变量（左值）               | a 是地址值（右值）                   | p = a 是正确，a = p 错误                                     |
    | 可自增减和赋值运算             | 只可按下标访问元素                   |                                                              |
    | 取地址运算                     | 取地址得到为`int (*)[N]`             | 用`&a+1`会直接跳过整个数组（偏移量是`N*sizeof(int)`），而`a+1`只跳过一个`int`元素 |
    | 需要在堆区申请内存才能作为数组 | 可定义并分配连续的空间               |                                                              |
    | p 相当于不定长数组             | a 是数组类型空间的首地址             | 声明中 *p 等价于 p []，因此 p [] 不能用于数组定义            |
    | sizeof (p) 返回**指针字节数**  | sizeof (a) 返回 a **数组空间字节数** | p 不具备数组类型特征，即无法从 p 获得数组元素数量            |

    - 指针指向元素，直接声明变量后取地址即可；指针指向数组，需要 malloc 分配内存空间

    | 维度             | 指针的数组（“存储指针的数组”）                               | 数组的指针（“指向整个数组的指针”）                           |
    | ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
    | **语法形式**     | `类型 *数组名[数组长度]`（例：`int *p[3]`）                  | `类型 (*指针名)[数组长度]`（例：`int (*p)[3]`）              |
    | **优先级逻辑**   | `[]` 优先级高于 `*`，因此是 “数组”，元素是指针               | 括号改变优先级，`*` 先绑定指针，因此是 “指针”，指向数组      |
    | **本质**         | 是**数组**，数组的每个元素是 “指针”                          | 是**指针**，指针指向 “整个数组”（而非单个元素）              |
    | **类型示例**     | `int *[3]`（存储 3 个`int*`指针的数组）                      | `int (*)[3]`（指向长度为 3 的`int`数组的指针）               |
    | **内存结构**     | 连续的 N 个指针空间（每个指针占 8/4 字节），每个指针可指向任意地址 | 单个指针空间（8/4 字节），指向一块连续的 “数组内存”（例：`int[3]`占 12 字节） |
    | **常见用法**     | 1. 实现变长二维结构（如三角矩阵） <br/>2. 存储字符串常量（如`char *strs[] = {"a","b"}`） | 1. 遍历数组（通过指针偏移访问整个数组） <br/>2. 作为函数参数传递整个数组（避免数组名退化） |
    | **`sizeof`结果** | 数组总字节数 = 指针个数 × 单个指针字节数（例：`sizeof(int *[3])=3×8=24`） | 指针本身的字节数（例：`sizeof(int (*)[3])=8`，与系统位数有关） |
    | **典型操作**     | `p[i]`：访问数组的第 i 个指针；`*p[i]`：访问指针指向的内容   | `*p`：访问指针指向的整个数组；`(*p)[i]`：访问数组的第 i 个元素 |

    - 二维数组的不同表示

        ```c
        int m[3][4];//二维数组
        // 形参写 int m[3][4] 或 int m[][4] 均可（列数必须指定，行数可省略）
        void traverse_by_array(int m[][4]) {
            printf("=== 二维数组直接遍历 ===\n");
            // i：行索引（0~2），j：列索引（0~3）
            for (int i = 0; i < 3; i++) {
                for (int j = 0; j < 4; j++) {
                    // 三种等价写法，任选其一
                    // printf("%d ", m[i][j]);
                    // printf("%d ", *(m[i] + j));  // m[i]是第i行首元素地址（int*）
                    printf("%d ", *(*(m + i) + j)); // m是数组指针（int (*)[4]），m+i指向第i行
                }
                printf("\n");
            }
        }
        
        int (*p)[4] = m;//指向数组的指针
        //括号()让p先与*结合，所以p是指针；指针指向的类型是int[4](即“4个int元素的一维数组”)
        // 形参类型必须是 int (*)[4]（数组指针类型，括号不能少）
        void traverse_by_array_ptr(int (*p)[4]) {
            printf("\n=== 数组指针遍历 ===\n");
            // 方式1：用索引（和二维数组语法一致，本质是指针偏移）
            for (int i = 0; i < 3; i++) {
                for (int j = 0; j < 4; j++) {
                    // 三种等价写法：p[i][j] = (*(p+i))[j] = *(*(p+i) + j)
                    printf("%d ", p[i][j]);
                }
                printf("\n");
            }
        
            // 方式2：纯指针偏移（更直观体现数组指针特性）
            printf("=== 数组指针纯偏移遍历 ===\n");
            int (*temp)[4] = p; // 用临时指针，避免修改原指针p的指向
            for (int i = 0; i < 3; i++) {
                int *col_ptr = *temp; // 解引用数组指针，得到当前行的int*指针
                for (int j = 0; j < 4; j++) {
                    printf("%d ", *col_ptr++); // 列指针偏移，访问当前行元素
                }
                temp++; // 数组指针偏移，指向 next 行（步长=4个int）
                printf("\n");
            }
        }
        
        int *(mp[3]) = {m[0], m[1], m[2]};//（指向数组的）指针的数组
        //[]优先级比*高，所以mp先与[3]结合，是 “含3个元素的数组”；数组的每个元素类型是 int*(指向int的指针)
        // 形参类型是 int*[3]（指针数组类型），也可写 int**（数组名退化为指针）
        void traverse_by_ptr_array(int *mp[3]) {
            printf("\n=== 指针数组遍历 ===\n");
            // i：指针数组的索引（0~2），对应3个int*指针
            for (int i = 0; i < 3; i++) {
                // j：列索引（0~3），通过mp[i]（int*）偏移访问列
                for (int j = 0; j < 4; j++) {
                    // 三种等价写法：mp[i][j] = *(mp[i] + j) = *(*(mp + i) + j)
                    printf("%d ", mp[i][j]);
                }
                printf("\n");
            }
        
            // 方式2：纯指针偏移（体现指针数组的数组特性）
            printf("=== 指针数组纯偏移遍历 ===\n");
            int **temp = mp; // 指针数组名退化为二级指针（指向第一个int*元素）
            for (int i = 0; i < 3; i++) {
                int *col_ptr = *temp; // 取当前int*指针（指向当前行首元素）
                for (int j = 0; j < 4; j++) {
                    printf("%d ", *col_ptr++); // 列指针偏移
                }
                temp++; // 二级指针偏移，指向 next int*元素（即下一行的指针）
                printf("\n");
            }
        }
        
        int **pp = mp;//（指向）指针（数组）的指针
        // 形参类型是 int**（二级指针类型，指向int*）
        void traverse_by_double_ptr(int **pp) {
            printf("\n=== 二级指针遍历 ===\n");
            // 方式1：模拟二维索引（本质是二级指针偏移）
            for (int i = 0; i < 3; i++) {
                for (int j = 0; j < 4; j++) {
                    // 核心逻辑：pp+i 指向第i个int*指针（即mp[i]）
                    // *(pp+i) 取出第i行的int*指针
                    // *(pp+i) + j 指向第i行第j列元素
                    printf("%d ", *(*(pp + i) + j));
                    // 注意：pp[i][j] 等价于 *(*(pp+i)+j)，语法上也支持（模拟二维数组）
                    // printf("%d ", pp[i][j]);
                }
                printf("\n");
            }
        
            // 方式2：纯指针偏移（更清晰体现二级指针的间接性）
            printf("=== 二级指针纯偏移遍历 ===\n");
            int **temp = pp; // 临时指针，避免修改原pp
            for (int i = 0; i < 3; i++) {
                int *col_ptr = *temp; // 第一次解引用：得到当前行的int*指针
                for (int j = 0; j < 4; j++) {
                    printf("%d ", *col_ptr++); // 第二次解引用：访问列元素
                }
                temp++; // 二级指针偏移，指向 next int*指针（下一行）
                printf("\n");
            }
        }
        ```

        | 变量 | 本质                   | 类型         | 关键特征                      |
        | ---- | ---------------------- | ------------ | ----------------------------- |
        | `m`  | 二维数组（数组的数组） | `int[3][4]`  | 连续存储，数组名是数组指针    |
        | `p`  | 数组指针               | `int (*)[4]` | 指向一维数组，步长为 4 个 int |
        | `mp` | 指针数组               | `int*[3]`    | 数组元素是 int* 指针          |
        | `pp` | 二级指针               | `int**`      | 指向 int* 指针                |
