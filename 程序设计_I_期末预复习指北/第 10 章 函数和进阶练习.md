# 第 10 章 函数和进阶练习
- `assert` 断言
    - `assert` 是 `<assert.h>` 头文件中定义的宏（不是函数），基本用法如下：
```c
#include<assert.h>
assert(exp);
```
- 当程序运行到 assert(表达式) 时：
    - 若 表达式为真（非 0）：assert 不做任何操作，程序继续执行
    - 若 表达式为假（0）：assert 会向标准错误流（stderr）输出错误信息，包含：
        - 断言失败的文件名（__FILE__）
        - 断言失败的行号（__LINE__）
        - 失败的表达式本身
        - 然后调用 abort() 函数终止程序（异常退出）
- 调试完成后，可通过定义`NDEBUG` 让编译器忽略`assert` 语句
```c
#define NDEBUG  // 定义后，所有assert都会被忽略
#include <assert.h>
assert(exp);  // 此时，该语句被编译器视为空操作，不执行
```
- 头文件`.h`
    - 头文件中通常包含：**共享的函数声明**，**全局变量的声明与初始化**和**定义的预处理符号或宏**
    - **头文件中函数与变量不能用 static 修饰**
    - 常用的预处理指令和宏：
        - `#include` ：用于包含头文件
        - `#define` ：用于定义 “宏”（预处理器会在代码中把所有 “宏名” 替换为**设定的文本**），分为无参数宏（常量）和带参数宏（类似函数的文本替换）
        - 宏的特殊运算符（常与`#define` 指令结合使用）
            - `#` ：将宏的参数转换为字符串常量（自动添加双引号，保留空格，无论参数是标识符、表达式还是字面量）
            - `##` ：将两个 token（标识符、关键字等）拼接成一个新的 token
        - 条件编译指令：
            1. #ifdef / #ifndef / #endif 
                - ifdef 宏名：如果 “宏名” **已被定义**，则保留后续代码，直到 #endif
                - ifndef 宏名：如果 “宏名” **未被定义**，则保留后续代码，直到 #endif
            2. #if / #elif / #else / #endif 
        - `#undef` ：用于取消已定义的宏，使其后续不再有效
        - `#error` ：当预处理器遇到 #error 时，会立即停止预处理并输出指定错误信息，导致编译失败（与条件编译指令结合用于强制检查条件）
        - `#pragma` ：用于向编译器传递特定指令（不同编译器支持的 #pragma 不同，属于非标准指令）
        - 预定义宏：C 语言标准规定了一些预定义宏，可直接使用
| 预定义宏       | 含义                                  | 示例输出                  |
|----------------|---------------------------------------|---------------------------|
| `__FILE__`     | 当前源文件名（字符串）                | "main.c"                  |
| `__LINE__`     | 当前代码行号（整数）                  | 10                        |
| `__DATE__`     | 编译日期（字符串，格式："MMM DD YYYY"）| "Oct 05 2023"             |
| `__TIME__`     | 编译时间（字符串，格式："HH:MM:SS"）   | "15:30:45"                |
| `__STDC__`     | 若编译器遵循ANSI C标准，值为1         | 1                         |
- 预处理指令的执行顺序：
    1. 处理所有 `#include`，插入头文件内容  
    2. 处理 `#define` 和 `#undef`，进行宏定义和取消  
    3. 处理条件编译指令（`#ifdef`、`#if` 等），保留或删除代码  
    4. 处理其他指令（如 `#pragma`）  
    5. 最终生成“纯C代码”，进入编译阶段
