# 第 16 章 指针与字符串、函数
1. #### const 指针

    1. ##### `const` 的核心作用

        `const` 是 C/C++ 中的**类型限定符**，用于限定**左值表达式**的可修改性：

        - 被 `const` 限定的对象 / 表达式，**只能在初始化时赋值，后续无法修改其左值**（即不能作为赋值操作的左值）

    2. ##### `const` 与指针的组合形式

        指针与 `const` 结合时，需根据 `const` 的位置区分**两种核心语义**，再扩展到多层指针场景

        1. 修饰「指针指向的对象」

        `const` 写在**类型名之后、`*` 之前**（或直接写在类型名前），表示**指针指向的对象是不可修改的**

        - 语法示例：`const int *p`（等价于 `int const *p`）

        - 含义：

            - `p` 是一个指针，指向的 `int` 类型对象被 `const` 限定
            - 允许修改指针 `p` 本身（即 `p` 可以指向其他对象），但**不允许通过 `*p` 修改指向的对象**

        - 对应操作：

            ```c
            p = &x;
            //允许修改指针指向
            ```

            ```c
            *p = 5;
            //Error! 不允许修改指针指向的对象
            ```

        2. 修饰「指针变量本身」

        `const` 写在 **`*` 之后、指针变量名之前 **，表示**指针变量本身是不可修改的**

        - 语法示例：`int *const p`

        - 含义：

            - `p` 是一个被 `const` 限定的指针，指向 `int` 类型对象
            - 允许通过 `*p` 修改指向的对象，但**不允许修改指针 `p` 本身（即 `p` 不能指向其他对象）**

        - 对应操作：

            ```c
            *p = 5;
            //允许修改指针指向的对象
            ```

            ```c
            p = &x;
            //Error! 不允许修改指针指向
            ```

        3. 同时修饰「指向的对象 + 指针本身」

        结合上述两种场景，`const` 同时修饰「指向的对象」和「指针本身」

        - 语法示例：`const int *const p`

        - 含义：

            - 指针 `p` 本身不可修改，且其指向的 `int` 对象也不可修改

        - 对应操作：

            ```c
            p = &x;
            //Error! 不允许修改指针指向
            ```

            ```c
            *p = 5;
            //Error! 不允许修改指针指向的对象
            ```

        4. 多层指针的 `const` 修饰

        对于多层指针（如二级指针），`const` 可分别修饰「每一层的指针」或「最终指向的对象」，需逐层分析：

        - 示例：`const int *const *const pp`
            - 第一层（`pp`）：`const` 修饰二级指针 `pp` 本身，`pp` 不可修改
            - 第二层（`*pp`）：`const` 修饰一级指针 `*pp` 本身，`*pp` 不可修改
            - 第三层（`**pp`）：`const` 修饰最终指向的 `int` 对象，`**pp` 不可修改

    3. ##### `const` 的语法注意事项

        1. **`const` 在「类型与 `*` 之间」的写法**：

            - 语法上，`int const *p` 等价于 `const int *p`（均表示「指向的对象不可修改」）
            - 但为了可读性，**建议优先使用 `const int \*p`**，避免与「指针本身不可修改」的场景混淆

        2. **`const` 限定的类型兼容性**：

            - 「非 `const` 类型」可**隐式转换**为「`const` 类型」（安全，避免修改 `const` 对象）：

                ```c
                int x = 2; const int *p = &x;
                ```

            - 「`const` 类型」不能直接赋值给「非 `const` 类型」（风险，可能修改 `const` 对象），需**显式强制转型**：

                ```c
                const int *a = &x; int *p1 = a;//出现编译错误
                ```

                ```c
                const int *a = &x; int *p1 = (int*)a;//应显式转换，需自行保证安全
                ```

    4. ##### 函数声明中的 `const` 用法

        当数组作为函数参数时，会退化为指针；`const` 可用于限定数组参数的「指针本身」或「指向的元素」：

        1. `double x[const]`：等价于 `double *const x`，表示**数组退化为的指针本身不可修改**
        2. `const double x[]`：等价于 `const double *x`，表示**数组退化为的指针所指向的元素不可修改**

    5. ##### 应用示例（代码 + 注释说明）

        ```c
        #include <stdio.h>
        int main() {
            // 1. const 修饰普通对象：对象不可修改
            const int n = 1;
            n = 2;  // ❌ 错误：const 对象不能赋值
        
            // 2. const 修饰「指向的对象」：*p 不可修改，p 可修改
            int x = 2;
            const int *p = &x;
            *p = 3;  // ❌ 错误：*p 是 const 限定的左值
            p = &n;  // ✅ 正确：p 本身可修改
        
            // 3. const 修饰「指针本身」：p 不可修改，*p 可修改
            int *const q = &x;
            *q = 3;  // ✅ 正确：*q 可修改
            q = NULL; // ❌ 错误：q 是 const 限定的指针
        
            // 4. 类型兼容性：非 const → const 隐式转换；const → 非 const 显式转型
            int *p1 = 0;
            const int *a = p1;  // ✅ 正确：非 const 转 const
            p1 = a;             // ❌ 错误：const 转非 const 需显式转型
            p1 = (int*)a;       // ✅ 正确：显式强制转型
        
            return 0;
        }
        ```

2. #### 字符串字面量

    1. ##### 字符串字面量的存储与常指针特性

        字符串字面量（如 `"STUDENT"`）是 C/C++ 中**以双引号包裹的字符序列**，其核心存储与使用特性如下：

        1. 字符串字面量的存储位置

        字符串字面量在**编译阶段**会被存储到程序的**只读数据段**（与可执行代码段一起加载），该内存区域的内容**仅允许读取、不允许修改**

        2. `char* s` 与 `char t[N]` 初始化字符串字面量的差异

        以 `"STUDENT"` 为例，两种初始化方式的本质完全不同：

        - **`char* s = "STUDENT";`**：
            - 等价于 `s = (char*)("STUDENT");`，即指针 `s` 直接指向**只读数据段中 `"STUDENT"` 的起始地址**
            - 此时 `s` 是指向「只读内存」的指针，**不能通过 `s` 修改字符串内容**（否则会触发「段错误」）
        - **`char t[8] = "STUDENT";`**：
            - 等价于「先分配栈上数组 `t[8]`，再通过 `memcpy` 将只读段中 `"STUDENT"` 的内容复制到 `t` 中」
            - 此时 `t` 是栈上的普通数组，**存储的是字符串字面量的副本**，允许修改 `t` 的内容（如 `t[0] = 'T'` 是合法的）

        3. 字符串字面量的不可修改性

        由于字符串字面量存储在只读数据段，直接修改其内容会违反内存保护规则：

        ```c
        char* s = "STUDENT";
        *s = 'T'; // ❌ 错误：尝试修改只读内存，触发段错误
        ```

        **建议**：用 `const char* s` 声明字符串字面量指针（显式表明不可修改），可减少误操作 BUG

        4. 相同字符串字面量的唯一性

        ```c
        char* s1 = "STUDENT";
        char* s2 = "STUDENT";
        printf("%d\n", s1 == s2); // 输出 1（地址相同）
        ```

    2. ##### 字符串字面量与数组（指针数组、二维数组）

        当字符串字面量作为数组元素时，需区分「指针数组」与「二维数组」的差异

        1. 指针数组 `char *ss[]` 的特性

        `char *ss[]` 是**存储指针的数组**，每个元素可指向只读数据段中的字符串字面量：

        ```c
        // ss 是指针数组，每个元素指向只读段中的字符串字面量
        char *ss[] = {"hello", "hello", "!"};
        char **pp = ss; // pp 是指向指针数组的二级指针
        ```

        - 指针数组的每个元素（如 `ss[0]`）是指向只读段的指针，**不能通过 `ss[0]` 修改字符串内容**
        - 由于相同字面量仅存储一份，指向相同字面量的指针地址相等（如 `ss[0] == ss[1]`）

        2. 二维数组 `char t[N][M]` 初始化的限制

        二维数组 `char t[N][M]` 是**连续的栈内存块**，不能直接用多个字符串字面量初始化（需逐个元素赋值）：

        ```c
        // ❌ 错误：二维数组不能直接用多个字符串字面量初始化
        char sa[10][10] = {"hello", "hello", "!"};
        ```

        若需用字符串字面量初始化二维数组，需显式为每行赋值：

        ```c
        // 正确：逐行为二维数组赋值
        char sa[3][10];
        strcpy(sa[0], "hello");
        strcpy(sa[1], "hello");
        strcpy(sa[2], "!");
        ```

        3. 指针数组的常见错误操作

        指针数组的元素是指向只读段的指针，修改其指向的内容会触发段错误：

        ```c
        char *ss[] = {"hello", "hello", "!"};
        char **pp = ss;
        pp[0][0] = 'H'; // ❌ 错误：尝试修改只读内存，触发段错误
        ```

4. #### void 指针

    1. ##### `void*` 指针的基础定义与语法限制

        `void*` 是 C 语言中的**通用指针类型**，其核心特性是「仅存储指针的地址值，忽略指向数据的类型信息」

        - 定义

            `void*` 指针仅保存内存地址，不关联「指向对象的类型、大小」等信息，因此是一种「无类型指针」

        - 语法限制

            由于 `void*` 不包含指向数据的类型信息（无法确定解引用后的数据占用字节数），编译器**禁止直接对 `void*` 执行以下操作**：

            - 解引用操作（`*`）：无法确定解引用后的数据大小
            - 下标运算（`[]`）：本质是「指针偏移 + 解引用」，同样依赖类型信息

    2. ##### `void*` 指针的类型转换规则

        `void*` 是 C 语言的「通用指针」，支持灵活的类型转换：

        1. **任意类型指针 → `void*`**：可**隐式转换**（无需强制类型转换）

            例：`int* int_p; void* void_p1 = int_p;`（`int*` 隐式转为 `void*`）

        2. **`void* → 任意类型指针`**：在 C 语言中可**隐式转换**（C++ 需显式强制转换）

            例：`void* void_p2; char* char_p = (char*)void_p2;`

        ⚠️ 注意：

        虽然转换灵活，但**类型不匹配的转换易导致逻辑错误**（如 `int** p`（二维数组指针）与 `int* q`（一维数组指针）类型不兼容，仅通过 `void*` 转换会隐藏类型风险，但是编译器不会警告）

    3. ##### `void*` 指针实现函数的「泛型参数」

        由于 `void*` 可接收任意类型的指针，结合 `size_t` 指定数据的字节大小，可实现**通用（泛型）函数**（即能处理任意类型数据的函数）

        - 示例 1：`MemRepeat`（同类型数据填充数组）

        ```c
        // 功能：用src指向的同类型数据，填充dest指向的数组（共填充count个元素）
        void* MemRepeat(void *dest, void *src, size_t src_sz, size_t count) {
            assert(dest && src); // 确保指针非空
            void *p = dest;
            for (int i=0; i<count; i++) {
                memcpy(p, src, src_sz); // 按字节复制src的数据到p
                p += src_sz; // 指针按“单个元素的大小（src_sz）”偏移
            }
            return dest;
        }
        ```

        为什么用 `void*`：

        `dest`/`src` 可接收任意类型的指针（如 `int*`、`double*`），结合 `src_sz`（单个元素的字节大小），即可处理任意类型的数组，实现「泛型填充」

        - 示例 2：`Printx`（打印任意类型的字节表示）

        ```c
        // 功能：打印p指向数据的字节级十六进制值（可查看任意类型的二进制存储）
        void Printx(void *p, size_t bytes_count) {
            assert(p); // 确保指针非空
            for (int i=0; i<bytes_count; i++, p++) {
                // 转换为unsigned char*，按字节读取数据并打印十六进制
                printf("%02x ", *(unsigned char*)p);
            }
            printf("\n");
        }
        ```

        为什么用 `void*`：

        `p` 可接收任意类型的指针（如 `double*`、`struct*`），结合 `bytes_count`（数据的总字节数），即可按字节打印任意类型的数据，实现「泛型打印」

5. #### 函数指针

    1. ##### 函数指针的定义

        函数指针的本质是**指针变量**，但它与指向普通数据（如`int`、`char`、数组）的指针不同：普通指针指向数据的内存地址，而函数指针指向**函数的入口地址**

        C 语言中，每个函数在编译后会被分配一段连续的内存空间用于存储指令，函数名本身就是该函数入口地址的 “常量标识”；函数指针则是存储这个入口地址的变量，通过它可以**间接调用**对应的函数

        1.1 函数指针的声明语法

        函数指针的声明必须严格匹配目标函数的 “返回值类型” 和 “参数类型列表”，通用格式为：

        ```
        返回值类型 (*函数指针变量名)(参数类型1, 参数类型2, ...);
        ```

        关键注意点：

        - 括号`(*变量名)`不可省略：因为`*`的优先级低于`()`，若写成`返回值类型 *变量名(参数列表)`，会被解析为 “返回值为指针类型的函数”，而非函数指针
        - 类型严格匹配：函数指针的返回值类型、参数个数 / 类型 / 顺序，必须与指向的函数完全一致，否则会导致未定义行为

        1.2 基础示例：函数指针的定义与调用

        以下示例展示如何定义函数指针，并通过它调用普通函数：

        ```c
        #include <stdio.h>
        
        // 普通函数：计算两数之和
        int add(int a, int b) {
            return a + b;
        }
        
        // 普通函数：计算两数之差
        int sub(int a, int b) {
            return a - b;
        }
        
        int main() {
            // 1. 定义函数指针：指向“返回int、接收两个int参数”的函数
            int (*fp)(int, int);
            
            // 2. 将add函数的地址赋值给函数指针（函数名直接代表入口地址）
            fp = add;
            // 3. 通过函数指针调用add函数（两种写法等价）
            printf("3 + 5 = %d\n", fp(3, 5));       // 写法1：直接调用
            printf("3 + 5 = %d\n", (*fp)(3, 5));    // 写法2：显式解引用（兼容老式写法）
            
            // 4. 重新指向sub函数，动态切换目标函数
            fp = sub;
            printf("8 - 2 = %d\n", fp(8, 2));
            
            return 0;
        }
        ```

        #### 运行结果：

        ```plaintext
        3 + 5 = 8
        3 + 5 = 8
        8 - 2 = 6
        ```

    2. ##### 函数指针的作用

        函数指针的核心价值在于**解耦代码逻辑、提升灵活性**，具体可归纳为以下 4 点：

        ###### 2.1 实现 “回调函数”（核心用途）

        回调函数是指 “由用户定义，但由系统 / 库函数在特定时机调用” 的函数，通过函数指针，用户可以将自定义逻辑传递给通用库函数，让库函数的行为可定制

        ###### 2.2 运行时动态选择函数

        程序可根据运行时的条件（如用户输入、状态变化）动态切换要执行的函数，避免编写大量`if-else`/`switch`分支，代码更简洁、易扩展

        ###### 2.3 提升代码复用性与抽象性

        将 “通用逻辑”（如遍历数组、排序）与 “具体业务逻辑”（如数据比较、元素处理）分离：通用逻辑只需接收函数指针参数，即可适配不同业务场景，无需重复编写通用逻辑

        ###### 2.4 简化函数表管理

        将一组功能同类的函数指针存入数组（函数指针数组），通过下标快速调用，适合处理菜单、命令集、驱动接口等场景

    3. 函数指针的实际用途

        - 回调函数（以标准库`qsort`为例）

            `qsort`是 C 标准库的通用快速排序函数，可排序任意类型的数组（`int`、`char`、结构体），其核心是通过函数指针接收用户自定义的 “比较规则”

            ```c
            #include <stdio.h>
            #include <stdlib.h>
            #include <string.h>
            
            // 定义结构体：学生信息
            typedef struct {
                char name[20];
                int score;
            } Student;
            
            // 自定义比较函数：按分数升序排序（符合qsort的比较函数规范）
            // 返回值：<0则a在前，=0则相等，>0则b在前
            int compareByScore(const void *a, const void *b) {
                // 强制类型转换（qsort的参数是void*，需转为目标类型）
                const Student *stuA = (const Student *)a;
                const Student *stuB = (const Student *)b;
                return stuA->score - stuB->score;
            }
            
            // 自定义比较函数：按姓名字典序排序
            int compareByName(const void *a, const void *b) {
                const Student *stuA = (const Student *)a;
                const Student *stuB = (const Student *)b;
                return strcmp(stuA->name, stuB->name);
            }
            
            int main() {
                Student students[] = {
                    {"ZhangSan", 85},
                    {"LiSi", 92},
                    {"WangWu", 78}
                };
                int n = sizeof(students) / sizeof(students[0]);
            
                // 1. 按分数排序：传递compareByScore的地址给qsort
                qsort(students, n, sizeof(Student), compareByScore);
                printf("按分数升序排序：\n");
                for (int i = 0; i < n; i++) {
                    printf("%s: %d\n", students[i].name, students[i].score);
                }
            
                // 2. 按姓名排序：仅更换比较函数指针，通用排序逻辑无需修改
                qsort(students, n, sizeof(Student), compareByName);
                printf("\n按姓名排序：\n");
                for (int i = 0; i < n; i++) {
                    printf("%s: %d\n", students[i].name, students[i].score);
                }
            
                return 0;
            }
            ```

            运行结果：

            ```
            按分数升序排序：
            WangWu: 78
            ZhangSan: 85
            LiSi: 92
            
            按姓名排序：
            LiSi: 92
            WangWu: 78
            ZhangSan: 85
            ```

        - 用途 2：动态选择函数（计算器程序）

            通过函数指针动态选择加减乘除函数，替代大量`if-else`分支：

            ```c
            #include <stdio.h>
            
            // 四则运算函数
            int add(int a, int b) { return a + b; }
            int sub(int a, int b) { return a - b; }
            int mul(int a, int b) { return a * b; }
            int div(int a, int b) { 
                if (b == 0) {
                    printf("错误：除数不能为0\n");
                    return 0;
                }
                return a / b; 
            }
            
            int main() {
                int a, b;
                char op;
                // 定义函数指针数组（函数表）：存储4个运算函数的地址
                int (*calcFp[])(int, int) = {add, sub, mul, div};
                char ops[] = "+-*/"; // 与函数数组下标对应
            
                printf("输入表达式（如 10+5）：");
                scanf("%d%c%d", &a, &op, &b);
            
                // 遍历运算符，匹配后调用对应函数
                for (int i = 0; i < 4; i++) {
                    if (op == ops[i]) {
                        printf("结果：%d\n", calcFp[i](a, b));
                        return 0;
                    }
                }
            
                printf("错误：无效运算符\n");
                return 1;
            }
            ```

            运行示例：

            ```
            输入表达式（如 10+5）：10*5
            结果：50
            ```
