# 第 6 章 循环结构
- 有条件地重复执行程序片段，就是循环

- while 循环：首先判断循环条件表达式是否为真，若是则执行后面的语句块，直到条件判断为假时跳出
- do……while 循环：首先执行循环体语句，然后判断循环条件表达式，若真则返回重新执行循环体语句，直到循环条件表达式为假
- for 循环：基本格式为：`for(表达式 1; 表达式 2; 表达式 3)`，其中：
    - 表达式 1 用于设置初始值，只执行一次
    - 表达式 2 为循环条件表达式，根据表达式的真假来决定是否继续执行循环
    - 表达式 3 负责修改循环变量，每次执行完循环体后才进行
    - 表达式 1 和表达式 3 都可以是逗号表达式
    - for 循环和 while 循环之间可以相互替换：
```c++
int sum = 0;
for(int i = 0; i <= 10; i++)
{
    sum += i;
}
```
<center>等价于</center>

```c++
int i = 1, sum = 0;
while( i <= 10 )
{
    sum += i;
    i++;
}
```
