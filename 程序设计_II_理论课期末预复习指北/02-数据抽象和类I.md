# 数据抽象和类 I

## `1` 抽象数据类型

- `1.1` 抽象与概念

    **抽象** `Abstraction` 是人类认知复杂世界的基本方式——通过提取事物区别于其他事物的特征来识别和描述事物。

    **概念** `Concept` 是对一类事物共同特征的概括。例如生物分类学中，"猫科"是概念，猫和老虎共享该概念的特征。概念包含两类特征：

    | 特征类型 | 说明 | 示例 |
    |---------|------|------|
    | 数据特征 | 描述事物的外观、状态及其值 | 猫的毛色、体重 |
    | 行为特征 | 描述事物能执行的操作 | 猫会奔跑、捕猎 |

    **总结**：抽象的本质是「抓特征、去细节」，用有限的属性刻画一类事物的共性。

- `1.2` 抽象数据类型

    **抽象数据类型** `Abstract Data Type, ADT` 是现实世界概念在程序中的数字化描述，是一种用户自定义的数据类型。

    一个完整的 ADT 包含两部分：

    1. **声明部分**：说明该 ADT 是什么以及如何使用——描述数据值的特性和可施加的操作。用户只需了解声明，无需知晓内部实现。
    2. **实现部分**：完成操作的具体逻辑。

    以 `DATE` 类型为例：

    | 组成部分 | 内容 |
    |---------|------|
    | 数据 | `year`, `month`, `day` |
    | 操作 | `set()`, `get()`, `increment()`, `decrement()` |

    **总结**：ADT 的核心思想是「接口与实现分离」，用户通过公开接口使用数据，内部细节对外不可见。

- `1.3` ADT 的设计目标

    将 `DATE` 设计为 ADT 后，达成以下效果：

    - 内部封装年月日数据及可执行的操作
    - 用户可定义多个 `DATE` 对象（变量）
    - 用户只能调用对象公开的接口，无法直接访问被隐藏的内部数据
    - 用户无需关心各操作的具体实现

    由此实现 **信息隐藏** `Information Hiding` 与 **封装** `Encapsulation`。

    > 与 C 语言 `struct` 的对比：C 的 `struct` 只能包含成员变量，数据与操作数据的函数彼此分离，无法自然地将二者绑定在一起。

    **总结**：ADT 通过封装把数据和行为捆绑为不可分割的整体，同时向用户隐藏实现细节。

## `2` 类的声明

- `2.1` 类的基本语法

    **类** `Class` 是 C++ 中实现 ADT 的核心机制，是用户自定义的数据类型。

    类声明的基本形式：

    ```cpp
    class 类名 {
        访问说明符:
            数据成员声明;
            函数成员声明;
    };
    ```

    类成员分为两类：

    | 成员类型 | 说明 | 访问控制 |
    |---------|------|---------|
    | 数据成员 | 按声明顺序存储，对齐规则同 C 结构体 | 通常设为 `private` 隐藏保护 |
    | 函数成员 | 操作数据成员的函数 | `public` 供外部访问，`private` 仅限内部使用 |

    访问说明符：

    - `public`：公有，对象使用者可访问
    - `private`：私有，仅对象内部可访问
    - `protected`：受保护，后续课程详述

    **总结**：类 = 数据成员 + 函数成员 + 访问控制，是定义数据类型的蓝图。

- `2.2` `class` 与 `struct` 的区别

    | 特性 | C 语言 | C++ `struct` | C++ `class` |
    |------|--------|-------------|------------|
    | 可包含成员函数 | 否 | 是 | 是 |
    | 类型名称 | `struct 标识符` | 直接为标识符 | 直接为标识符 |
    | 默认访问权限 | 公有 | 公有 | 私有 |

    > 除默认访问权限不同外，`class` 与 `struct` 在语法和语义上完全一致。

    **总结**：C++ 中 `struct` 和 `class` 都是类关键字，区别仅在于默认访问权限。

- `2.3` 封装原则

    标准封装做法：

    1. 在 `private` 区域定义数据成员
    2. 在 `public` 区域定义操作这些数据的函数成员

    这样外部代码只能通过成员函数修改对象状态，保持内部一致性。若将数据成员暴露为 `public`，客户端可直接赋非法值（如线段长度为负数），破坏逻辑一致性。

    **总结**：数据隐藏、接口公开，是保障对象状态合法性的基本手段。

## `3` 成员函数及实现

- `3.1` 成员函数声明

    **成员函数** `Member Function` 是声明在类定义内部的函数，可操作类的任意对象并访问对象中的所有成员。

    ```cpp
    class DATE {
    public:
        void Set(int, int, int);
        int getMonth() const;
        int getDay() const;
        int getYear() const;
        void Print() const;
        void Increment();
        void Decrement();
    private:
        int month, day, year;
    };
    ```

    **总结**：成员函数将操作与数据绑定，是面向对象编程中「行为依附于对象」的体现。

- `3.2` 成员函数的内联定义

    在类定义体内直接实现的成员函数，自动被视为 **内联函数** `Inline Function`，即使未显式使用 `inline` 关键字。

    ```cpp
    class DATE {
    public:
        void Set(int newYear, int newMonth, int newDay) {
            month = newMonth;
            day = newDay;
            year = newYear;
        }
        // ...
    };
    ```

    **总结**：类内定义的成员函数隐含 `inline`，适合简短函数以节省调用开销。

- `3.3` 成员函数的外部定义

    在类外部定义成员函数时，需使用 **作用域解析运算符** `Scope Resolution Operator` `::` 指明该函数属于哪个类。

    ```cpp
    class DATE {
    public:
        void Set(int newYear, int newMonth, int newDay);
        // ...
    };

    void DATE::Set(int newYear, int newMonth, int newDay) {
        month = newMonth;
        day = newDay;
        year = newYear;
    }
    ```

    外部实现文件中必须 `#include` 对应的头文件，因为类中声明的标识符作用域仅限于类声明内部，外部文件需通过 `::` 指明成员函数归属。

    **总结**：`类名::函数名` 是类外实现成员函数的固定语法，编译器据此建立函数与类的关联。

- `3.4` `const` 成员函数

    在成员函数参数列表后加 `const` 关键字，表示该函数不会修改对象的数据成员。

    ```cpp
    int DATE::getMonth() const {
        return month;  // 只读访问，不可修改
    }
    ```

    > 若 `const` 成员函数内部尝试修改数据成员，编译器将报错。

    **总结**：`const` 成员函数承诺不修改对象状态，是接口契约的一部分。

## `4` 对象创建与使用

- `4.1` 类与对象的关系

    | 概念 | 定义 | 特点 |
    |------|------|------|
    | 类 `Class` | 用户定义的数据类型，表示一个 ADT | 蓝图/模板，不含实际数据 |
    | 对象 `Object` / 实例 `Instance` | 类定义的变量 | 占用实际内存，自动对象或动态对象的默认初始值不确定 |
    | 客户端 `Client` | 使用类的软件代码 | 通过对象的公有方法处理数据 |

    **总结**：类是「型」，对象是「值」；类定义结构，对象承载数据。

- `4.2` 对象的创建

    通过类名定义变量即可创建对象：

    ```cpp
    DATE date;  // 创建 DATE 类的一个对象 date
    ```

    **总结**：对象创建语法与普通变量定义相同，类名即类型名。

- `4.3` 成员的访问

    通过 **点运算符** `Dot Operator` `.` 访问对象的成员变量和成员函数：

    ```cpp
    date.Set(2022, 1, 30);  // 调用公有成员函数
    // date.month = 1;      // Error: month 是私有成员
    ```

    访问规则：

    - `public` 成员：可在类外部任意访问
    - `private` 成员：仅在类内部或友元中可访问

    **总结**：点运算符是对象访问成员的唯一方式，访问权限由声明时的访问说明符控制。

## `5` 构造函数与析构函数

- `5.1` 构造函数

    **构造函数** `Constructor` 是类的一种特殊成员函数，在创建类的新对象时自动执行，用于完成初始化等逻辑。

    特征：

    1. 函数名与类名完全相同
    2. 不返回任何类型（包括 `void`）
    3. 若用户未定义，编译器自动生成默认构造函数（无参、函数体为空）

    ```cpp
    class Line {
    public:
        Line();  // 构造函数声明
        // ...
    };

    Line::Line() {
        std::cout << "Object is being created" << std::endl;
    }
    ```

    **总结**：构造函数在对象诞生时自动调用，是对象初始化的「入口」。

- `5.2` 带参数的构造函数

    构造函数可以带有参数，在创建对象时传入初始值：

    ```cpp
    class Line {
    public:
        Line(double len);  // 带参构造函数
        // ...
    };

    Line::Line(double len) {
        length = len;
    }
    ```

    调用方式：

    ```cpp
    Line line(10.0);   // 正确：调用带参构造
    // Line line1;     // Error：用户定义构造函数后，编译器不再提供默认构造
    ```

    > 一旦用户自定义了任何构造函数，编译器便不再自动生成默认构造函数。

    **总结**：带参构造函数让对象在诞生时就拥有确定的初始状态。

- `5.3` 构造函数的默认参数

    构造函数可使用默认实参，减少重载数量：

    ```cpp
    class Line {
    public:
        Line(double len = 0);  // 默认参数
        // ...
    };

    Line line;       // 等价于 Line(0)
    Line line1(10);  // 等价于 Line(10)
    ```

    > 默认参数只能出现在参数列表的右侧。

    **总结**：默认参数让一个构造函数适配多种调用形式，兼顾灵活性与简洁性。

- `5.4` 构造函数重载

    同一个类可以定义多个构造函数，参数列表不同即可构成重载：

    ```cpp
    class DATE {
    public:
        DATE();                    // 无参构造
        DATE(int, int, int);       // 有参构造
        // ...
    };
    ```

    调用时编译器根据实参自动匹配：

    ```cpp
    DATE date1;                 // 调用无参构造
    DATE date2(1976, 12, 20);   // 调用有参构造
    ```

    C++11 后建议为参数提供默认值，实现「一个构造函数，多种调用」：

    ```cpp
    DATE(int = 2000, int = 1, int = 1);

    DATE date1;              // (2000, 1, 1)
    DATE date2(1976);        // (1976, 1, 1)
    DATE date3(1976, 12);    // (1976, 12, 1)
    DATE date4(1976, 12, 20);// (1976, 12, 20)
    ```

    **总结**：构造函数重载让对象能以多种方式初始化，默认参数可进一步简化重载数量。

- `5.5` 析构函数

    **析构函数** `Destructor` 是类的特殊成员函数，在对象被释放前自动执行，用于释放资源。

    特征：

    1. 函数名与类名相同，前缀加波浪号 `~`
    2. 不返回任何值，不带任何参数
    3. 不可直接调用

    ```cpp
    class Line {
    public:
        Line();   // 构造函数
        ~Line();  // 析构函数
        // ...
    };

    Line::~Line() {
        std::cout << "Object is being deleted" << std::endl;
    }
    ```

    **总结**：析构函数是对象生命周期的「出口」，负责清理资源、善始善终。

## `6` This 指针

- `6.1` This 指针的概念

    **This 指针** 是 C++ 中每个对象隐含的指针，指向对象自身的地址。它是所有成员函数的隐含参数，在成员函数内部可用于指向调用该函数的对象。

    特征：

    - 友元函数没有 `this` 指针（友元不是类的成员）
    - 静态成员函数没有 `this` 指针
    - 当成员函数参数与数据成员重名时，必须用 `this` 区分

    ```cpp
    class Box {
    public:
        int compare(Box box) {
            return this->Volume() > box.Volume();
        }
    };
    ```

    **总结**：`this` 指针让成员函数明确知道「当前正在操作的是哪个对象」。

## `7` 静态成员

- `7.1` 静态数据成员

    **静态数据成员** `Static Data Member` 是类的组成部分，但不属于任何具体对象。它在类的所有对象之间共享，具有静态（全局）生存期。

    声明与定义：

    ```cpp
    // DATE.h
    class DATE {
    public:
        // ...
        static int count;  // 声明
    };

    // DATE.cpp
    int DATE::count = 0;  // 类外定义且初始化，不可再加 static
    ```

    特征：

    - 必须通过类名和作用域解析运算符访问：`DATE::count`
    - 不通过构造函数初始化
    - 必须在类定义体外部恰好定义一次

    **总结**：静态数据成员是「属于类而非对象」的共享数据，用于记录类级别的全局状态。

- `7.2` 静态成员函数

    **静态成员函数** `Static Member Function` 同样属于类而不属于任何对象。

    特征：

    - 没有 `this` 指针
    - 不能直接访问非静态数据成员或非静态成员函数
    - 只能直接访问静态数据成员或静态成员函数
    - 若访问控制允许，可通过 `类名::函数名()` 直接调用

    ```cpp
    class DATE {
    public:
        static void getCount();
        // ...
    };

    void DATE::getCount() {
        cout << "There are " << count << " objects now" << endl;
    }

    // 调用
    DATE::getCount();   // 通过类名调用
    date1.getCount();   // 通过对象调用（也可）
    ```

    **总结**：静态成员函数操作静态数据，不依赖具体对象，是类级别的「工具函数」。

## `8` C++ 预备知识补充

- `8.1` `bool` 类型

    C++ 定义了三个关键字：`bool`、`true`、`false`。

    - 显式或隐式转换为 `bool` 时：0 值 $ightarrow$ `false`，非 0 值 $ightarrow$ `true`
    - `cout << true` 输出 `1`，`cout << false` 输出 `0`

- `8.2` 空参数列表

    C++ 中 `func()` 等价于 `func(void)`，表示无参数。可变参数用 `...` 表示。

- `8.3` 函数重载

    C++ 允许声明同名函数，只要参数类型或数量不同。编译器根据 **函数签名** `Function Signature`（函数名 + 参数数量 + 参数类型）区分不同重载版本。

    ```cpp
    void Swap(int& x, int& y);
    void Swap(double& x, double& y);
    ```

- `8.4` 默认参数

    函数参数可指定默认值，调用时可省略右侧参数：

    ```cpp
    void func(int n = 1, float b = 1.2, char c = '@');

    func();           // func(1, 1.2, '@')
    func(10);         // func(10, 1.2, '@')
    func(20, 9.8);    // func(20, 9.8, '@')
    ```

    > 默认参数只能定义在参数列表的右侧。

## `9` 应用：向量 `Vector3`

- `9.1` 设计要点

    `Vector3` 是表示三维向量和点的数据类型，设计要点：

    | 组成 | 内容 |
    |------|------|
    | 数据成员 | `x`, `y`, `z`（`float` 类型） |
    | 成员函数 | `getMagnitude()`, `set()`, `toString()` |
    | 构造函数 | 带参构造，支持部分默认参数 |
    | 静态成员 | `zero`, `one`, `right`, `up`, `forward` |
    | 静态函数 | `Distance()`, `Cross()`, `Dot()` |

    **总结**：`Vector3` 综合运用了类声明、成员函数、构造函数、静态成员等全部本章知识点。
